# Privacy Policy

You can use the practice site without creating an account. The site does not include project-operated analytics or advertising trackers.

- **Mock tests.** The site saves your attempt, including answers and timing, in this browser’s local storage. It uses this data to resume or review practice. Clear the site’s browser data to remove stored attempts.
- **Navigation preferences.** The site saves your sidebar visibility and last expanded section in this browser’s local storage. Clear the site’s browser data to reset these preferences.
- **Cognitive Lab.** The lab holds session names, answers and notes in the open page. You can export a report to your device. Use a nickname if needed, avoid entering sensitive information and share exported reports only with the people you choose.
- **Search.** The site filters a downloaded question index in your browser. Search terms and selected filters can appear in the page URL and browser history, so avoid entering personal information.
- **Hosting and external links.** GitHub Pages hosts the site and states that it logs and stores visitor IP addresses for security purposes. GitHub and any external sites you visit handle data under their own policies. See the [GitHub Pages hosting notice](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) and the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

GitHub issues are public. Keep personal and classroom information out of reports posted there.
