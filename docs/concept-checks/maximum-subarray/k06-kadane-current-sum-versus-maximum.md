# Kadane current sum versus maximum

## Question

For nums = [4,-6,3,2], what are currentSum and maxSum after all elements are processed?

## Options

| Option | Answer choice |
| --- | --- |
| A | currentSum = 5, maxSum = 5 |
| B | currentSum = 5, maxSum = 4 |
| C | currentSum = 3, maxSum = 5 |
| D | currentSum = 2, maxSum = 5 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. currentSum = 5, maxSum = 5

## Explanation

The best suffix ends at 2 and is [3,2], with sum 5. It is also the global maximum.
