# One sliding window update

## Question

For arr = [4,2,7,1,5] and k = 3, the first window sums to 13. What is the next window's sum?

## Options

| Option | Answer choice |
| --- | --- |
| A | 13 |
| B | 10 |
| C | 14 |
| D | 8 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 10

## Explanation

Remove 4 and add 1: 13 - 4 + 1 = 10.
