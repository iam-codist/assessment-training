# Ping protocol

## Question

Which protocol is normally used by ping to request a response?

## Options

| Option | Answer choice |
| --- | --- |
| A | SMTP |
| B | DHCP |
| C | FTP |
| D | ICMP |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. ICMP

## Explanation

Ping typically sends an ICMP Echo Request and waits for an Echo Reply.
