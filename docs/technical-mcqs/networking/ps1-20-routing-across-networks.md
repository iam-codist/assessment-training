# Routing across networks

## Question

Two devices need to communicate across different IP networks. Which device normally forwards traffic between them?

## Options

| Option | Answer choice |
| --- | --- |
| A | Repeater |
| B | Hub |
| C | Unmanaged Layer 2 switch |
| D | Router |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Router

## Explanation

A router uses destination IP addresses and routing information to forward packets between networks.
