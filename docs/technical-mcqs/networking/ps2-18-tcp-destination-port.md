# TCP destination port

## Question

Which value identifies a destination application on a TCP host?

## Options

| Option | Answer choice |
| --- | --- |
| A | MAC vendor prefix |
| B | Subnet mask |
| C | Time to live |
| D | Destination port |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Destination port

## Explanation

The destination port identifies the receiving transport endpoint.
