# Resolving an IPv4 neighbor

## Question

An Ethernet host knows a neighbor's IPv4 address on the same local network. What resolves the neighbor's MAC address?

## Options

| Option | Answer choice |
| --- | --- |
| A | ICMP |
| B | TCP |
| C | ARP |
| D | DNS |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. ARP

## Explanation

ARP maps a local-link IPv4 address to a link-layer address.
