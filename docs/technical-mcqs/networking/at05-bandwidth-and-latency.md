# Bandwidth and latency

## Question

Two links both report a 20 ms round trip, but one can carry twice as many bits per second. What is higher on that link?

## Options

| Option | Answer choice |
| --- | --- |
| A | Latency |
| B | Bandwidth |
| C | Loss rate |
| D | Round-trip time |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Bandwidth

## Explanation

Bandwidth describes capacity in bits per second. The two round-trip delays are equal.
