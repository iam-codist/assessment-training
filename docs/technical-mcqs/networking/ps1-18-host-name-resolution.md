# Host name resolution

## Question

Which service resolves a host name to an IP address?

## Options

| Option | Answer choice |
| --- | --- |
| A | DHCP |
| B | SMTP |
| C | DNS |
| D | NTP |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. DNS

## Explanation

DNS records associate names with addresses. DHCP supplies network configuration to clients.
