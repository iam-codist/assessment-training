# Default gateway

## Question

A packet's destination is outside the local subnet and there is no more specific route. Where does the host normally send it?

## Options

| Option | Answer choice |
| --- | --- |
| A | DNS server |
| B | Loopback interface |
| C | Every local host |
| D | Default gateway |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Default gateway

## Explanation

The default gateway is the next hop for destinations without a specific route.
