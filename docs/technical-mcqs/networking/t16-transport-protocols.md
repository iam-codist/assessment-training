# Transport protocols

## Question

Which transport protocol provides an ordered byte stream with retransmission of lost data?

## Options

| Option | Answer choice |
| --- | --- |
| A | TCP |
| B | UDP |
| C | ARP |
| D | ICMP |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. TCP

## Explanation

TCP provides an ordered byte stream and uses acknowledgments and retransmission to recover from loss. Delivery is not guaranteed forever if a connection fails.
