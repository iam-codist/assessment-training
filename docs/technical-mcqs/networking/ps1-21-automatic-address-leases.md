# Automatic address leases

## Question

Which protocol normally leases an IP address and supplies a default gateway to a new client?

## Options

| Option | Answer choice |
| --- | --- |
| A | HTTPS |
| B | DHCP |
| C | DNS |
| D | SMTP |

<details>
<summary>Show answer and explanation</summary>

## Answer

## Explanation
