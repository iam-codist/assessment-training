# Password reuse after a breach

## Question

A breach at one service exposes passwords and a user reused that password elsewhere. Which habit limits the impact in future?

## Options

| Option | Answer choice |
| --- | --- |
| A | Use unique passwords across services |
| B | Make the same password longer everywhere |
| C | Reuse only on trusted sites |
| D | Store all passwords in a shared document |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Use unique passwords across services

## Explanation

Unique credentials prevent disclosure at one site from directly exposing the password used at another.
