# Offboarding access

## Question

A suspended employee can still enter a system because their account has active privileges. Which control directly addresses this?

## Options

| Option | Answer choice |
| --- | --- |
| A | Compress old logs |
| B | Move the server |
| C | Revoke access as part of offboarding |
| D | Increase the login timeout |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Revoke access as part of offboarding

## Explanation

Removing account privileges and ending active sessions prevents continued authorized access.
