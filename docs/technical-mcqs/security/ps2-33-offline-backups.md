# Offline backups

## Question

Which practice reduces damage if ransomware encrypts shared files?

## Options

| Option | Answer choice |
| --- | --- |
| A | Use longer filenames |
| B | Maintain tested offline backups |
| C | Share one admin account |
| D | Disable version retention |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Maintain tested offline backups

## Explanation

An offline copy can be restored even if the live share is encrypted.
