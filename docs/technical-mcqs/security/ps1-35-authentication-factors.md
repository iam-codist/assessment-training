# Authentication factors

## Question

Which sign-in flow uses two distinct authentication factor types?

## Options

| Option | Answer choice |
| --- | --- |
| A | Password and authenticator app code |
| B | Password and PIN |
| C | Two different passwords |
| D | Password entered twice |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Password and authenticator app code

## Explanation

A password represents knowledge and an authenticator app code represents possession. Two knowledge checks remain one factor type.
