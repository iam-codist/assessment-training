# Encrypted connections

## Question

What protection does correctly configured HTTPS primarily add to HTTP traffic between a browser and a server?

## Options

| Option | Answer choice |
| --- | --- |
| A | A guarantee that all website content is truthful. |
| B | Automatic removal of malware from the computer. |
| C | Permanent anonymity from the website operator. |
| D | Encryption and integrity protection in transit, with server authentication. |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Encryption and integrity protection in transit, with server authentication.

## Explanation

HTTPS uses TLS to protect data in transit and authenticate the server. A fraudulent site can also have HTTPS; it does not certify the truth of its content.
