# Least privilege

## Question

A support dashboard only needs to view tickets. Which permission best follows least privilege?

## Options

| Option | Answer choice |
| --- | --- |
| A | Organization admin |
| B | Edit all tickets |
| C | Read and delete tickets |
| D | Read tickets only |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Read tickets only

## Explanation

Granting read access alone restricts the dashboard to the operation it needs.
