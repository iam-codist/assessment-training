# Individual admin accounts

## Question

What is the safest way to handle a shared admin account used by several employees?

## Options

| Option | Answer choice |
| --- | --- |
| A | Issue individual accounts with scoped access |
| B | Post the password in chat |
| C | Keep the password unchanged indefinitely |
| D | Disable audit logs |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Issue individual accounts with scoped access

## Explanation

Individual accounts support accountability and access can be scoped and revoked per person.
