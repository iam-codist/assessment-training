# Monitoring unexpected access

## Question

A manager needs to investigate who changed an access policy and when. What should the system retain?

## Options

| Option | Answer choice |
| --- | --- |
| A | An audit log of policy changes |
| B | Only daily file sizes |
| C | The public landing page |
| D | The monitor brightness settings |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. An audit log of policy changes

## Explanation

An audit trail records the actor, action and time needed to investigate changes.
