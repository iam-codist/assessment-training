# Laptop disk encryption

## Question

What protects the contents of a powered-off laptop drive if the laptop is stolen?

## Options

| Option | Answer choice |
| --- | --- |
| A | Full-disk encryption |
| B | Screen brightness lock |
| C | Network segmentation |
| D | Application logging |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Full-disk encryption

## Explanation

Encryption makes raw disk contents unreadable without the decryption material.
