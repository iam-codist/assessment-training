# Authorization after sign-in

## Question

An authenticated employee can view a payroll record outside their role. What failed?

## Options

| Option | Answer choice |
| --- | --- |
| A | IP address leasing |
| B | Identity verification |
| C | File compression |
| D | Authorization |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Authorization

## Explanation

Authentication confirms identity. Authorization decides which records and actions that identity can access.
