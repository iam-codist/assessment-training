# Access data integrity

## Question

An EmployeeID field is the primary key of an Employees table. Which requirement must its values satisfy?

## Options

| Option | Answer choice |
| --- | --- |
| A | They must uniquely identify each record and cannot be null. |
| B | They must always be sequential with no gaps. |
| C | They must contain only employee names. |
| D | They must be identical in every row. |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. They must uniquely identify each record and cannot be null.

## Explanation

A primary key uniquely identifies a record and cannot contain a null key value. Sequential numbering without gaps is not required.
