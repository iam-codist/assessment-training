# Transaction atomicity

## Question

Which transaction property ensures both sides of a bank transfer succeed together or both are rolled back?

## Options

| Option | Answer choice |
| --- | --- |
| A | Isolation |
| B | Durability |
| C | Availability |
| D | Atomicity |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Atomicity

## Explanation

Atomicity makes all operations in the transaction succeed as one unit or roll back together.
