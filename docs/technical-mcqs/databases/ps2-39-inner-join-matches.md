# Inner join matches

## Question

What does an INNER JOIN return?

## Options

| Option | Answer choice |
| --- | --- |
| A | Rows with a matching join condition |
| B | Every left row |
| C | Every right row |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Rows with a matching join condition

## Explanation

An inner join returns only combinations that satisfy its join predicate.
