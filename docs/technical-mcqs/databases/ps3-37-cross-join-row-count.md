# Cross join row count

## Question

What does a CROSS JOIN produce for tables with 3 and 4 rows?

## Options

| Option | Answer choice |
| --- | --- |
| A | 7 rows |
| B | 4 rows |
| C | 12 rows |
| D | 3 rows |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 12 rows

## Explanation

The Cartesian product pairs each of the 3 rows with all 4 rows.
