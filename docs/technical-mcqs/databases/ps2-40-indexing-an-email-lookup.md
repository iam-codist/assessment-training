# Indexing an email lookup

## Question

Why might a database index on email help a lookup by email?

## Options

| Option | Answer choice |
| --- | --- |
| A | It always reduces storage |
| B | It automatically hides email |
| C | It replaces backups |
| D | It can locate matching rows with less scanning |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. It can locate matching rows with less scanning

## Explanation

An index offers an access path to matching values, though it uses storage and adds write overhead.
