# Descending sort order

## Question

What does ORDER BY total DESC do?

## Options

| Option | Answer choice |
| --- | --- |
| A | Sorts smallest totals first |
| B | Filters out zeros |
| C | Sorts largest totals first |
| D | Groups equal totals |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Sorts largest totals first

## Explanation

DESC orders the specified expression from high to low.
