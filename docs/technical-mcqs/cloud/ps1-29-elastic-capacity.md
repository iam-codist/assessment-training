# Elastic capacity

## Question

An app adds instances during peak demand and removes them as traffic falls. Which property does this illustrate?

## Options

| Option | Answer choice |
| --- | --- |
| A | Deduplication |
| B | Elasticity |
| C | Encryption |
| D | Durability |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Elasticity

## Explanation

Elasticity is the ability to adjust provisioned resources as demand changes.
