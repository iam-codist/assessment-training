# Managed application platforms

## Question

Developers deploy application code to a managed runtime while the provider maintains the underlying operating system. Which model best fits this description?

## Options

| Option | Answer choice |
| --- | --- |
| A | On-premises hosting |
| B | IaaS only |
| C | A local virtual machine |
| D | PaaS |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. PaaS

## Explanation

In PaaS, the provider manages the underlying platform and operating system while the customer deploys application code.
