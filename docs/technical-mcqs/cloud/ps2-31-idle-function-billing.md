# Idle function billing

## Question

Which configuration typically reduces the compute charge for an idle serverless function billed per execution?

## Options

| Option | Answer choice |
| --- | --- |
| A | Keep a dedicated VM running |
| B | Prewarm it continuously |
| C | Let it remain idle with no reserved capacity |
| D | Generate requests every minute |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Let it remain idle with no reserved capacity

## Explanation

With per-execution billing and no reserved capacity, idle periods normally incur no execution charge.
