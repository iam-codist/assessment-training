# Vertical compute scaling

## Question

A reporting VM changes from 4 GB to 8 GB of RAM without adding instances. Which change did the team make?

## Options

| Option | Answer choice |
| --- | --- |
| A | Horizontal scaling |
| B | Replication |
| C | Vertical scaling |
| D | Object archiving |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Vertical scaling

## Explanation

Vertical scaling increases resources on an existing instance. Horizontal scaling adds instances.
