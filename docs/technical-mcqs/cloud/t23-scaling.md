# Scaling

## Question

An application responds to higher demand by increasing its instance count from 2 to 6, with each instance unchanged. What type of scaling is this?

## Options

| Option | Answer choice |
| --- | --- |
| A | Vertical scaling |
| B | Data compression |
| C | Horizontal scaling |
| D | Archiving |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Horizontal scaling

## Explanation

Adding more unchanged instances is horizontal scaling. Increasing the resources of an individual instance is vertical scaling.
