# Cloud responsibilities

## Question

For an ordinary cloud-hosted virtual machine, which responsibility normally remains with the customer?

## Options

| Option | Answer choice |
| --- | --- |
| A | Replacing failed physical disks in the provider datacenter. |
| B | Patching the guest operating system and configuring application access. |
| C | Securing the provider datacenter building. |
| D | Maintaining the provider physical network switches. |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Patching the guest operating system and configuring application access.

## Explanation

For an ordinary IaaS VM, the customer manages guest-OS patching and application access. Physical hardware and facilities belong to the provider side.
