# Excel formatting

## Question

You want overdue dates to turn red automatically when they meet a date-based rule. Which feature is designed for this?

## Options

| Option | Answer choice |
| --- | --- |
| A | Conditional formatting |
| B | Mail merge |
| C | Freeze panes |
| D | Text to Columns |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Conditional formatting

## Explanation

Conditional formatting applies visual formatting when a rule is true; it does not change the underlying date.
