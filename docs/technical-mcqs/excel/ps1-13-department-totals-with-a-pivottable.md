# Department totals with a PivotTable

## Question

You need totals by department from hundreds of expense rows. Which feature summarizes them with department as a row field and expense as a summed value?

## Options

| Option | Answer choice |
| --- | --- |
| A | Freeze Panes |
| B | PivotTable |
| C | Data Validation |
| D | Find and Replace |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. PivotTable

## Explanation

A PivotTable groups records by department and can sum values for each group.
