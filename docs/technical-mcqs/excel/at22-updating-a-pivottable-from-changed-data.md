# Updating a PivotTable from changed data

## Question

A report changes values in cells already included in a PivotTable's source range. What updates the PivotTable to reflect the changes?

## Options

| Option | Answer choice |
| --- | --- |
| A | Freeze Panes |
| B | Refresh |
| C | Wrap Text |
| D | Page Break Preview |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Refresh

## Explanation

Refreshing recalculates the PivotTable from its source data.
