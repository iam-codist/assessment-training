# Excel counting

## Question

B1:B5 contain, in order, the text Approved, the number 0, a genuinely empty cell, the text Hold, and the number 12. What does =COUNTA(B1:B5) return?

## Options

| Option | Answer choice |
| --- | --- |
| A | 2 |
| B | 4 |
| C | 3 |
| D | 5 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 4

## Explanation

COUNTA counts nonempty cells, including text and numeric zero. Only the genuinely empty cell is excluded.
