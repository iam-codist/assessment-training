# Excel filtering

## Question

A table has 200 records. You filter its Status column to show only Pending. What normally happens to the records that do not match?

## Options

| Option | Answer choice |
| --- | --- |
| A | They are permanently deleted. |
| B | Their formulas are converted to values. |
| C | They move to another workbook. |
| D | Their rows are hidden from the filtered view. |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Their rows are hidden from the filtered view.

## Explanation

Filtering changes which rows are visible. It does not delete the other records.
