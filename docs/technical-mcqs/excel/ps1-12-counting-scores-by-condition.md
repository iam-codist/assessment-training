# Counting scores by condition

## Question

Which formula counts values at least 50 in B2:B20?

## Options

| Option | Answer choice |
| --- | --- |
| A | =COUNT(B2:B20) |
| B | =SUMIF(B2:B20,"\>=50") |
| C | =COUNTA(B2:B20) |
| D | =COUNTIF(B2:B20,"\>=50") |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. =COUNTIF(B2:B20,"\>=50")

## Explanation

COUNTIF counts cells meeting a criterion. SUMIF adds qualifying values.
