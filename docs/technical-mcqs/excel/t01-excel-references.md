# Excel references

## Question

Cell D3 contains =C3*$F$1. The formula is copied to D6. What formula does D6 contain?

## Options

| Option | Answer choice |
| --- | --- |
| A | =C3*$F$4 |
| B | =C6*$F$1 |
| C | =C6*$F$4 |
| D | =C3*$F$1 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. =C6*$F$1

## Explanation

Copying down three rows changes relative C3 to C6. Both the column and row in $F$1 remain fixed.
