# Average a range

## Question

Which formula gives the average of numeric values in C2:C9?

## Options

| Option | Answer choice |
| --- | --- |
| A | =COUNT(C2:C9) |
| B | =SUM(C2:C9) |
| C | =AVERAGE(C2:C9) |
| D | =MAX(C2:C9) |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. =AVERAGE(C2:C9)

## Explanation

AVERAGE divides the sum by the count of numeric cells.
