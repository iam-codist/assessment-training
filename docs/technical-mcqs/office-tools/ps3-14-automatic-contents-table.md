# Automatic contents table

## Question

## Options

| Option | Answer choice |
| --- | --- |
| A | Mail Merge |
| B | Footnotes |

<details>
<summary>Show answer and explanation</summary>

## Answer

## Explanation

An automatic contents table uses heading levels and can update its page references.
