# Word personalized documents

## Question

A team needs 250 letters with the same body but different names and postal addresses from a spreadsheet. Which Word feature is best suited to this?

## Options

| Option | Answer choice |
| --- | --- |
| A | Track Changes |
| B | Word Count |
| C | Mail Merge |
| D | Page Color |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Mail Merge

## Explanation

Mail Merge combines a reusable document with per-recipient fields from a data source.
