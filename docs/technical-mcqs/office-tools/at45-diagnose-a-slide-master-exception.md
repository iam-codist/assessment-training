# Diagnose a slide master exception

## Question

A PowerPoint deck uses a theme. One title was manually assigned a different font. After changing the theme font, that title still differs. What should you inspect first?

## Options

| Option | Answer choice |
| --- | --- |
| A | The monitor resolution |
| B | The slide transition duration |
| C | Local formatting on that title and its layout or placeholder settings |
| D | The Outlook inbox rules |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Local formatting on that title and its layout or placeholder settings

## Explanation

A local font override can keep a title different from the theme. Check whether it is a placeholder or an independent text box, then remove or correct the local formatting and use the intended layout. Transitions and mail rules do not determine the title font.

</details>
