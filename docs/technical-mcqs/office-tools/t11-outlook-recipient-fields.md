# Outlook recipient fields

## Question

You want to send an email to a manager and also copy an auditor without showing the auditor in the recipient list seen by the manager. Which field should contain the auditor?

## Options

| Option | Answer choice |
| --- | --- |
| A | To |
| B | Cc |
| C | Bcc |
| D | Subject |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Bcc

## Explanation

Bcc hides that recipient from the To/Cc recipients. It does not stop the Bcc recipient from replying or revealing their involvement.
