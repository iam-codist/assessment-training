# Checking slide order before a presentation

## Question

A briefing deck has 30 slides and two sections are in the wrong order. Which PowerPoint view makes it easiest to scan and drag groups of slide thumbnails?

## Options

| Option | Answer choice |
| --- | --- |
| A | Reading View |
| B | Slide Sorter |
| C | Notes Page |
| D | Slide Master |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Slide Sorter

## Explanation

Slide Sorter displays thumbnails together and lets you rearrange them.
