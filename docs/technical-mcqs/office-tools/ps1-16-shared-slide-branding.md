# Shared slide branding

## Question

## Options

| Option | Answer choice |
| --- | --- |
| A | Notes pane |
| B | Slide Sorter |

<details>
<summary>Show answer and explanation</summary>

## Answer

## Explanation

The master supplies shared design elements to slides that use it, subject to layout and slide settings.
