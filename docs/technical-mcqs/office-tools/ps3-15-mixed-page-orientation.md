# Mixed page orientation

## Question

Which Word feature starts a new part of a document with different page orientation?

## Options

| Option | Answer choice |
| --- | --- |
| A | Line break |
| B | Section break |
| C | Character style |
| D | Bookmark |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Section break

## Explanation

Sections can have independent page setup settings such as orientation.
