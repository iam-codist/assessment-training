# Waiting for disk I/O

## Question

A process waits for a disk read. Which state best describes it until the read completes?

## Options

| Option | Answer choice |
| --- | --- |
| A | Blocked |
| B | Running |
| C | Ready |
| D | Terminated |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Blocked

## Explanation

It cannot proceed until the I/O event occurs.
