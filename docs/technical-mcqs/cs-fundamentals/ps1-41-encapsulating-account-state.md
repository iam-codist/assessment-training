# Encapsulating account state

## Question

A class hides its balance field and exposes methods that validate deposits. Which principle is illustrated?

## Options

| Option | Answer choice |
| --- | --- |
| A | Recursion |
| B | Encapsulation |
| C | Sorting |
| D | Overloading |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Encapsulation

## Explanation

Encapsulation bundles state and behavior and controls how other code can change the state.
