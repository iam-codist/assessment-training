# Overloading and parameter types

## Question

A Java class declares send(String message) and send(int code). What does this illustrate?

## Options

| Option | Answer choice |
| --- | --- |
| A | Inheritance |
| B | Deadlock |
| C | Method overriding |
| D | Method overloading |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Method overloading

## Explanation

The class uses the same method name with different parameter lists. This is overloading.
