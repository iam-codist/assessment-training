# Scheduling fairness

## Question

A ready task waits indefinitely because higher-priority tasks keep arriving. What has happened?

## Options

| Option | Answer choice |
| --- | --- |
| A | Thrashing |
| B | Deadlock |
| C | Starvation |
| D | Recursion |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Starvation

## Explanation

Starvation occurs when a task is continually denied a resource. Other tasks can still make progress.
