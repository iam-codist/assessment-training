# Page-table translation

## Question

Which OS mechanism translates virtual addresses to physical frames with hardware support?

## Options

| Option | Answer choice |
| --- | --- |
| A | Polling |
| B | Buffering |
| C | Spooling |
| D | Paging |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Paging

## Explanation

Page tables map virtual pages to physical frames, with the MMU performing translation.
