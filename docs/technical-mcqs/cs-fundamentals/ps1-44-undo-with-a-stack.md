# Undo with a stack

## Question

Which data structure supports undoing the most recent action first?

## Options

| Option | Answer choice |
| --- | --- |
| A | FIFO queue |
| B | Set |
| C | Sorted array |
| D | Stack |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Stack

## Explanation

A stack uses last-in, first-out order. The last action pushed is the first one popped.
