# First-come scheduling

## Question

Which scheduling policy runs the earliest-arriving ready task first, without preemption?

## Options

| Option | Answer choice |
| --- | --- |
| A | Round robin |
| B | Shortest remaining time |
| C | Highest priority first |
| D | First-come, first-served |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. First-come, first-served

## Explanation

FCFS uses arrival order and lets the running task retain the CPU until it blocks or finishes.
