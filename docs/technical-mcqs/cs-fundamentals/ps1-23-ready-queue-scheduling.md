# Ready queue scheduling

## Question

A process is ready to run but waiting for CPU time. Which component selects it for execution?

## Options

| Option | Answer choice |
| --- | --- |
| A | CPU scheduler |
| B | File system |
| C | Device controller |
| D | Command shell |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. CPU scheduler

## Explanation

The CPU scheduler selects a runnable process or thread from the ready queue.
