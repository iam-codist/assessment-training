# Virtual address translation cache

## Question

A CPU repeatedly translates the same virtual pages. Which hardware cache normally stores recently used translations?

## Options

| Option | Answer choice |
| --- | --- |
| A | Page file |
| B | Translation lookaside buffer |
| C | DNS cache |
| D | Write-ahead log |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Translation lookaside buffer

## Explanation

The translation lookaside buffer stores recent virtual-to-physical mappings to reduce repeated page-table lookups.
