# Process memory reclamation

## Question

A process has finished and has been fully reclaimed by the OS. What happened to its allocated memory?

## Options

| Option | Answer choice |
| --- | --- |
| A | It became shared by every process |
| B | It was permanently reserved |
| C | It was released for reuse |
| D | It was copied into the program file |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. It was released for reuse

## Explanation

The OS reclaims resources such as allocated pages when cleaning up a process.
