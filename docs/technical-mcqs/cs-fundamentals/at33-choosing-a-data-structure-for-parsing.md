# Choosing a data structure for parsing

## Question

An editor checks whether brackets close in reverse order of opening. Which data structure fits?

## Options

| Option | Answer choice |
| --- | --- |
| A | FIFO queue |
| B | Stack |
| C | Hash set without order |
| D | Single Boolean |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Stack

## Explanation

A stack follows last-in, first-out order. The most recent opening bracket must be matched first.
