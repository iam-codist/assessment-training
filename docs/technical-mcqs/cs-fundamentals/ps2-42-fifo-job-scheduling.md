# FIFO job scheduling

## Question

Which data structure serves waiting jobs in arrival order?

## Options

| Option | Answer choice |
| --- | --- |
| A | Queue |
| B | Stack |
| C | Set |

<details>
<summary>Show answer and explanation</summary>

## Answer

## Explanation
