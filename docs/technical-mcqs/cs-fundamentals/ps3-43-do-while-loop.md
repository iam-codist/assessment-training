# Do-while loop

## Question

Which loop is appropriate when a menu must be displayed at least once before testing whether to exit?

## Options

| Option | Answer choice |
| --- | --- |
| A | While with an initially false condition |
| B | Do-while |
| C | A conditional with no loop |
| D | For loop with zero iterations |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Do-while

## Explanation

A do-while executes its body before checking the condition.
