# Excessive paging

## Question

What is excessive paging that leaves little time for useful work called?

## Options

| Option | Answer choice |
| --- | --- |
| A | Spooling |
| B | Buffering |
| C | Thrashing |
| D | Caching |

<details>
<summary>Show answer and explanation</summary>

## Answer

## Explanation

Frequent page faults and transfers can dominate execution.
