# Context switching

## Question

What is the term for saving one thread's execution state and restoring another's?

## Options

| Option | Answer choice |
| --- | --- |
| A | Page allocation |
| B | Context switch |
| C | File mapping |
| D | Deadlock |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Context switch

## Explanation

A context switch changes which execution context a CPU runs.
