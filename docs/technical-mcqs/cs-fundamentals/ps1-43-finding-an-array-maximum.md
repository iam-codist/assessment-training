# Finding an array maximum

## Question

What is the worst-case time complexity of scanning an unsorted array of n elements once to find the maximum?

## Options

| Option | Answer choice |
| --- | --- |
| A | O(n) |
| B | O(log n) |
| C | O(n²) |
| D | O(1) |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. O(n)

## Explanation

The algorithm must inspect all n values because the maximum can be anywhere.
