# Recursive sum

## Question

F(0) = 0. For n \> 0, F(n) = n + F(n − 1). What is F(4)?

## Options

| Option | Answer choice |
| --- | --- |
| A | 10 |
| B | 6 |
| C | 24 |
| D | 4 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 10

## Explanation

Expand the calls to 4 + 3 + 2 + 1 + 0 = 10.
