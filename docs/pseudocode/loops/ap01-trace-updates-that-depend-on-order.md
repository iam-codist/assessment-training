# Trace updates that depend on order

## Question

Start with x = 2 and y = 5. Repeat twice: set x to x + y, then set y to x - y using the updated x. What is (x, y) at the end?

## Options

| Option | Answer choice |
| --- | --- |
| A | 7, 2 |
| B | 9, 7 |
| C | 9, 2 |
| D | 12, 7 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 9, 7

## Explanation

The first pass gives (7, 2). The second pass uses those new values and gives (9, 7).
