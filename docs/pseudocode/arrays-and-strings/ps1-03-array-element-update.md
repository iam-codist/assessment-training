# Array element update

## Question

With zero-based indexing, A = [4, 8, 2]; A[1] = A[0] + A[2]. What is A[1]?

## Options

| Option | Answer choice |
| --- | --- |
| A | 6 |
| B | 8 |
| C | 10 |
| D | 12 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 6

## Explanation

Indices 0 and 2 contain 4 and 2, so index 1 is overwritten with 6.
