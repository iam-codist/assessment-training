# Sequential assignments

## Question

a = 3; b = 5; a = b; b = a. What are (a, b)?

## Options

| Option | Answer choice |
| --- | --- |
| A | (5, 3) |
| B | (3, 5) |
| C | (5, 5) |
| D | (3, 3) |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. (5, 5)

## Explanation

The first assignment loses the original 3. Both variables end up holding 5.
