# Recover OR using addition and AND

## Question

What is printed by this pseudocode?

```text
a = 12
b = 10
c = a + b - (a AND b)
PRINT c
```

<details>
<summary>Show answer and explanation</summary>

## Answer

14

## Explanation

a + b = (a AND b) + (a OR b). Subtracting 8 from 22 gives 14.
