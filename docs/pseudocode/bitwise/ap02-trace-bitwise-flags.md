# Trace bitwise flags

## Question

First compute 12 XOR 5. Then apply bitwise AND with 10. What is the final value?

## Options

| Option | Answer choice |
| --- | --- |
| A | 8 |
| B | 2 |
| C | 9 |
| D | 10 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 8

## Explanation

1100 XOR 0101 is 1001. AND with 1010 leaves 1000, which is 8.
