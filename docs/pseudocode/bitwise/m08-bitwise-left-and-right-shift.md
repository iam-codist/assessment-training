# Bitwise Left and Right Shift

## Question

What is printed by this pseudocode?

```text
INTEGER x = 5

x = x << 2
x = x >> 1

PRINT x
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 5 |
| B | 8 |
| C | 10 |
| D | 20 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 10

## Explanation

5 &lt;&lt; 2 = 20; 20 >> 1 = 10, assuming no overflow.
