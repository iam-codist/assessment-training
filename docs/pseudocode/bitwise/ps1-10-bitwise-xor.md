# Bitwise XOR

## Question

a = 6; b = 3. What is a XOR b using bitwise XOR?

## Options

| Option | Answer choice |
| --- | --- |
| A | 7 |
| B | 2 |
| C | 5 |
| D | 6 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 5

## Explanation

Binary 110 XOR 011 is 101. XOR sets each bit where the two input bits differ.
