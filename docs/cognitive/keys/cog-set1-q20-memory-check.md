# Memory Check

## Question

Entering a room picks up its key. A coloured bar is a locked door needing that colour of key (keys are reusable); thin grey links are open. Memory round: which colour of locked door appears the most times on the whole map?

| Row / Col | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 1 | A | B | C |
| 2 | D | E | F |
| 3 | G | H | I |

Start: **A**. Exit: **I**. Keys: D: R, E: B, F: G. R = red; G = green; B = blue.

Only the following links exist. Each move uses one link, in either direction.

| Rooms connected | Required key |
| --- | --- |
| A ↔ B | R |
| A ↔ D | Open |
| B ↔ C | R |
| B ↔ E | R |
| C ↔ F | B |
| D ↔ E | G |
| D ↔ G | Open |
| E ↔ F | Open |
| E ↔ H | R |
| F ↔ I | B |
| G ↔ H | G |
| H ↔ I | Open |

## Options

| Option | Answer choice |
| --- | --- |
| A | Red doors |
| B | All colours are equal |
| C | Blue doors |
| D | Green doors |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Red doors

## Explanation

Red doors: 4

Blue doors: 2

Green doors: 2

Red has the most locked doors.
