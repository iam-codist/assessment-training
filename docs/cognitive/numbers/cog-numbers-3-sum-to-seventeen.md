# Sum to seventeen

## Question

Choose three different digits from 1–9 to make the equation true. Each digit can be used once. Any valid solution is accepted.

```text
a + b + c = 17
```

<details>
<summary>Show answer and explanation</summary>

## Answer

One valid solution: a = 1, b = 7, c = 9.

## Explanation

Work backwards from the target. Check the brackets and the order of operations before committing to a combination. Multiple answers may be valid.

```text
1 + 7 + 9 = 17
```
