# Expressions · 08

## Question

Pop in ASCENDING order (smallest → largest).

| Bubble | Expression / number |
| --- | --- |
| A | 9×4+6 |
| B | 3×7+6 |
| C | 3×9+4 |
| D | 3×7−10 |
| E | 2×2+4 |

## Answer

2×2+4 → 3×7−10 → 3×7+6 → 3×9+4 → 9×4+6

## Explanation

Correct order: 2×2+4 → 3×7−10 → 3×7+6 → 3×9+4 → 9×4+6.
Evaluate each expression first, then compare the values in the direction requested.
