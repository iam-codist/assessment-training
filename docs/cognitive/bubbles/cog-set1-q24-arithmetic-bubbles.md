# Arithmetic Bubbles

## Question

Bubbles with the values shown float on the screen. Each shows an expression. Pop them in ASCENDING order of value. Which bubble is popped 3rd?

| Bubble | Expression / number |
| --- | --- |
| A | 6 x 7 |
| B | 48 / 4 |
| C | 15 + 19 |
| D | 50 - 9 |
| E | 8² |
| F | 3 x 11 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 8² |
| B | 50 - 9 |
| C | 6 x 7 |
| D | 15 + 19 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 15 + 19

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 15 + 19.

| Expression / number | Value |
| --- | --- |
| 6 x 7 | 42 |
| 48 / 4 | 12 |
| 15 + 19 | 34 |
| 50 - 9 | 41 |
| 8² | 64 |
| 3 x 11 | 33 |

**Eligible pop order:** 48 / 4 → 3 x 11 → 15 + 19 → 50 - 9 → 6 x 7 → 8².
