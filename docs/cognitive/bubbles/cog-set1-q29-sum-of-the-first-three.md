# Sum of the First Three

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order. What is the sum of the first three bubbles popped?

| Bubble | Expression / number |
| --- | --- |
| A | 14 |
| B | 9 |
| C | 22 |
| D | 5 |
| E | 31 |
| F | 17 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 36 |
| B | 25 |
| C | 28 |
| D | 31 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 28

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

First three: 5 + 9 + 14 = 28.

| Expression / number | Value |
| --- | --- |
| 14 | 14 |
| 9 | 9 |
| 22 | 22 |
| 5 | 5 |
| 31 | 31 |
| 17 | 17 |

**Eligible pop order:** 5 → 9 → 14 → 17 → 22 → 31.
