# Powers and Roots

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order of value. Which bubble is popped immediately BEFORE 3³?

| Bubble | Expression / number |
| --- | --- |
| A | √64 |
| B | 3³ |
| C | 6² |
| D | 4² |
| E | √196 |
| F | 5² |

## Options

| Option | Answer choice |
| --- | --- |
| A | 5² |
| B | 6² |
| C | 4² |
| D | √196 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 5²

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 5².

| Expression / number | Value |
| --- | --- |
| √64 | 8 |
| 3³ | 27 |
| 6² | 36 |
| 4² | 16 |
| √196 | 14 |
| 5² | 25 |

**Eligible pop order:** √64 → √196 → 4² → 5² → 3³ → 6².
