# Filter and Order

## Question

Bubbles with the values shown float on the screen. Pop ONLY the bubbles greater than 20, in ASCENDING order. Which of them is popped 3rd?

| Bubble | Expression / number |
| --- | --- |
| A | 18 |
| B | 25 |
| C | 33 |
| D | 21 |
| E | 47 |
| F | 12 |
| G | 29 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 18 |
| B | 25 |
| C | 29 |
| D | 47 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 29

## Explanation

Convert every bubble to a plain number first.

Ignore the bubbles that fail the condition (greater than 20).

The answer is 29.

Skipped bubbles: 18, 12.

| Expression / number | Value |
| --- | --- |
| 18 | 18 |
| 25 | 25 |
| 33 | 33 |
| 21 | 21 |
| 47 | 47 |
| 12 | 12 |
| 29 | 29 |

**Eligible pop order:** 21 → 25 → 29 → 33 → 47.
