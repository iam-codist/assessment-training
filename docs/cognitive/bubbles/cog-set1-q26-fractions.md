# Fractions

## Question

Bubbles with the values shown float on the screen. Pop the fractions in ASCENDING order. Which bubble is popped 4th?

| Bubble | Expression / number |
| --- | --- |
| A | 3/4 |
| B | 5/8 |
| C | 2/3 |
| D | 7/10 |
| E | 4/5 |
| F | 1/2 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 7/10 |
| B | 1/2 |
| C | 2/3 |
| D | 5/8 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 7/10

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 7/10.

| Expression / number | Value |
| --- | --- |
| 3/4 | 0.75 |
| 5/8 | 0.625 |
| 2/3 | 0.666667 |
| 7/10 | 0.7 |
| 4/5 | 0.8 |
| 1/2 | 0.5 |

**Eligible pop order:** 1/2 → 5/8 → 2/3 → 7/10 → 3/4 → 4/5.

</details>
