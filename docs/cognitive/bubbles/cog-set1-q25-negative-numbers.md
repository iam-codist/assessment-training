# Negative Numbers

## Question

Bubbles with the values shown float on the screen. Pop them in DESCENDING order (largest first). Which bubble is popped LAST?

| Bubble | Expression / number |
| --- | --- |
| A | -7 |
| B | 3 |
| C | -15 |
| D | 0 |
| E | -2 |
| F | 9 |
| G | -11 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 9 |
| B | 0 |
| C | 3 |
| D | -15 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. -15

## Explanation

Convert every bubble to a plain number first.

Sort the values in descending (largest first) order.

The answer is -15.

| Expression / number | Value |
| --- | --- |
| -7 | -7 |
| 3 | 3 |
| -15 | -15 |
| 0 | 0 |
| -2 | -2 |
| 9 | 9 |
| -11 | -11 |

**Eligible pop order:** 9 → 3 → 0 → -2 → -7 → -11 → -15.
