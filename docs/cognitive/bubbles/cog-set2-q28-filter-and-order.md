# Filter and Order

## Question

Bubbles with the values shown float on the screen. Pop ONLY the bubbles less than 30, in DESCENDING order. Which of them is popped 2nd?

| Bubble | Expression / number |
| --- | --- |
| A | 34 |
| B | 12 |
| C | 27 |
| D | 45 |
| E | 19 |
| F | 28 |
| G | 8 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 28 |
| B | 19 |
| C | 27 |
| D | 34 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 27

## Explanation

Convert every bubble to a plain number first.

Ignore the bubbles that fail the condition (less than 30).

The answer is 27.

Skipped bubbles: 34, 45.

| Expression / number | Value |
| --- | --- |
| 34 | 34 |
| 12 | 12 |
| 27 | 27 |
| 45 | 45 |
| 19 | 19 |
| 28 | 28 |
| 8 | 8 |

**Eligible pop order:** 28 → 27 → 19 → 12 → 8.
