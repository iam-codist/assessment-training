# Negative Numbers

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order (smallest first). Which bubble is popped 2nd?

| Bubble | Expression / number |
| --- | --- |
| A | -4 |
| B | 8 |
| C | -13 |
| D | 0 |
| E | -9 |
| F | 5 |
| G | -1 |

## Options

| Option | Answer choice |
| --- | --- |
| A | -1 |
| B | 0 |
| C | 8 |
| D | -9 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. -9

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is -9.

| Expression / number | Value |
| --- | --- |
| -4 | -4 |
| 8 | 8 |
| -13 | -13 |
| 0 | 0 |
| -9 | -9 |
| 5 | 5 |
| -1 | -1 |

**Eligible pop order:** -13 → -9 → -4 → -1 → 0 → 5 → 8.
