# Decimal Trap

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order. Which bubble is popped 5th?

| Bubble | Expression / number |
| --- | --- |
| A | 0.6 |
| B | 0.45 |
| C | 0.075 |
| D | 0.8 |
| E | 0.5 |
| F | 0.09 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 0.8 |
| B | 0.5 |
| C | 0.6 |
| D | 0.09 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 0.6

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 0.6.

| Expression / number | Value |
| --- | --- |
| 0.6 | 0.6 |
| 0.45 | 0.45 |
| 0.075 | 0.075 |
| 0.8 | 0.8 |
| 0.5 | 0.5 |
| 0.09 | 0.09 |

**Eligible pop order:** 0.075 → 0.09 → 0.45 → 0.5 → 0.6 → 0.8.
