# Sum of the First Three

## Question

Bubbles with the values shown float on the screen. Pop them in DESCENDING order. What is the sum of the first three bubbles popped?

| Bubble | Expression / number |
| --- | --- |
| A | 18 |
| B | 7 |
| C | 25 |
| D | 12 |
| E | 40 |
| F | 3 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 80 |
| B | 86 |
| C | 83 |
| D | 91 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 83

## Explanation

Convert every bubble to a plain number first.

Sort the values in descending (largest first) order.

First three: 40 + 25 + 18 = 83.

| Expression / number | Value |
| --- | --- |
| 18 | 18 |
| 7 | 7 |
| 25 | 25 |
| 12 | 12 |
| 40 | 40 |
| 3 | 3 |

**Eligible pop order:** 40 → 25 → 18 → 12 → 7 → 3.
