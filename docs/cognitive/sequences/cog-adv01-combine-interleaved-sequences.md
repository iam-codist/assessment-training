# Combine interleaved sequences

## Question

The odd-position terms increase by successive odd increments 3, 5, 7, 9. The even-position terms double. Find the missing term.

```text
2, 3, 5, 6, 10, 12, ?, 24, 26, 48
```


## Options

| Option | Answer choice |
| --- | --- |
| A | 14 |
| B | 16 |
| C | 17 |
| D | 20 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 17

## Explanation

Odd positions are 2, 5, 10, 17, 26 with differences 3, 5, 7, 9. Even positions are 3, 6, 12, 24, 48. Write the two position lists first. Verify both supplied final terms. Write the odd and even positions separately before comparing choices.
