# Summarize a meeting with actions

## Question

A meeting agrees that Asha will finish the UI on Tuesday, Ben will test it on Wednesday, and the demo depends on API access being ready. Write a short action summary.

<details>
<summary>Show answer and explanation</summary>

## Answer

“Asha will finish the UI on Tuesday. Ben will test it on Wednesday. API access remains a dependency for the demo; the team still needs to confirm its owner and delivery date.”

## Explanation

The summary separates agreed actions from an unresolved dependency. Do not invent an owner or deadline for API access. In real notes add calendar dates and share the summary for correction. Self-review: owners, actions, timing and uncertainty.
