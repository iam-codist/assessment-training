# A concise project status email

> Newly authored practice to complete the training roadmap. This is not a recovered chat question or an official assessment item.

## Question

Write a short email update: the interface is complete, API access is delayed, and you need a test account by Thursday to keep Friday’s demo on track.

<details>
<summary>Show answer and explanation</summary>

## Answer

Subject: Test account needed by Thursday for Friday demo

Hello team,

The interface is complete. API testing is waiting on a test account. Please provide access by Thursday so we can prepare for Friday’s demo. If access will arrive later, let me know so we can agree on a smaller demo scope.

Thank you.

## Explanation

The message gives status, blocker, action and timing. It avoids blaming an individual or making an unsupported promise. In real work include a specific calendar date when “Thursday” might be ambiguous. Self-review: can the reader identify the requested action in one reading?
