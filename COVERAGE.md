## How to use the Cognitive Lab

Choose an activity and read its rules before pressing **Play**. Start untimed to learn the pattern, then add a timer when you can solve it consistently. After submitting, check the explanation and jot down a shortcut to try next round.

Use the **Session summary** to revisit earlier rounds. Export it before closing or refreshing if you want to keep a record.
