# References and credits

This collection brings together original assessment practice, worked coding examples and adapted cognitive exercises. Question pages include references where available.

- **Coding practice:** `LC` IDs point to corresponding [LeetCode problems](https://leetcode.com/problemset/). The lessons use short paraphrases. Read the input and output carefully, especially when a practice variant uses different rules.
- **SQL:** Explore the [PostgreSQL joins tutorial](https://www.postgresql.org/docs/current/tutorial-join.html) for more examples. The [practice dataset](SQL-PRACTICE.md) gives you a small database to query locally.
- **Frontend:** Use the [MDN web development curriculum](https://developer.mozilla.org/en-US/docs/Learn_web_development) to review HTML, CSS and JavaScript concepts.
- **Cognitive exercises:** Image prompts are adapted from Accenture Cognitive Assessment Practice, Game Aptitude Test Session 02 (Geo-Sudo), and Gamified Aptitude practice slides. The [Cognitive Lab](https://iam-codist.github.io/assessment-training/lab/) lets you work through the puzzles interactively.
