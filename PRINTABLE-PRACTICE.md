# Printable practice sets

Three original Accenture-style classroom practice sets. Each set has 45 technical MCQs, a SQL joins exercise and an HTML/CSS/JavaScript exercise.

- [Student handouts (PDF, 21 pages)](practice/printable/student-handouts.pdf) include all questions and starter code.
- [Trainer copies (PDF, 15 pages)](practice/printable/trainer-copies.pdf) include the answer grids, explanations, worked solutions and marking criteria.

| Set | SQL joins | HTML, CSS and JavaScript |
| --- | --- | --- |
| 1 | Active employees by department | Workshop seat counter |
| 2 | Paid order totals | Ticket price calculator |
| 3 | Passing course enrollments | Live course search |

Each PDF is formatted for A4 and has a bookmark for each set. Use the student handouts for practice and open the trainer copies when you are ready to review your answers.
