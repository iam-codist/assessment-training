# Repeated letters in an anagram

## Question

For s = "aabbcc" and t = "abcabc", what does frequency counting return?

## Options

| Option | Answer choice |
| --- | --- |
| A | true — all frequency counts cancel |
| B | false — characters are in different positions |
| C | false — repeated characters are not allowed |
| D | Compilation error |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. true — all frequency counts cancel

## Explanation

Both strings contain two a, two b and two c characters.
