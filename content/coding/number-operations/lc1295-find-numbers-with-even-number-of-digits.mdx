# Find Numbers with Even Number of Digits

## Question

Count how many positive integers in an array have an even number of decimal digits.

## Example 1

**Input**

```text
[12,345,2,6,7896]
```

**Output**

```text
2
```

## Answer

Use the following algorithm to produce the result for any input that satisfies the question rules.

## Explanation
