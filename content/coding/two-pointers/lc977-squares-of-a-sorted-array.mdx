# Squares of a Sorted Array

## Question

Square every element of a nondecreasing integer array and return the squares in nondecreasing order.

## Example 1

**Input**

```text
[-4,-1,0,3,10]
```

**Output**

```text
[0,1,9,16,100]
```

## Notes

(-4) × (-4) = 16. Compare magnitudes or squares, not the original signed values.
