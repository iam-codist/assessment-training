# Valid Anagram

## Question

Determine whether two lowercase English strings contain exactly the same letters with the same frequencies, regardless of position.

## Example 1

**Input**

```text
anagram / nagaram; rat / car; aabbcc / abcabc
```

**Output**

```text
true; false; true
```
