# Group Anagrams

## Question

Group lowercase words containing identical letters with identical frequencies. Empty and repeated words are allowed. Group ordering may vary.

## Example 1

**Input**

```text
[eat,tea,bat,ate]
```

**Output**

```text
[eat,tea,ate] and [bat]
```

## Answer

Use the following algorithm to produce the result for any input that satisfies the question rules.

## Explanation

Use a sorted-word or frequency signature as a map key, then group words with matching keys.

## Solutions in four languages

Group order is normally unrestricted. These demonstration programs sort the group keys so all four languages print the same result. This adds ordering work beyond a hash-map solution. Input words use only lowercase English letters, so the JSON output needs no escaping.

These standalone programs use the same input and output contract. Choose a language on the website, or open a source file below.

Read n, then n lowercase English words, one per line (a word may be empty). Print groups as JSON arrays, ordered by sorted-letter key; retain input order inside each group.

**Sample program input**

```text
4
eat
tea
bat
ate
```

**Sample program output**

```text
["bat"]
["eat","tea","ate"]
```
