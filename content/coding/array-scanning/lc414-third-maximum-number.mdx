# Third Maximum Number

## Question

Return the third-largest distinct number in a nonempty integer array. If fewer than three distinct values exist, return the maximum.

## Example 1

**Input**

```text
[2,2,3,1]; [1,2]
```

**Output**

```text
1; 2
```
