# Grid delivery route

## Question

A courier starts at (0,0) and visits n locations in the given order. Between two locations, movement is horizontal or vertical only, and the courier always uses the shortest such route. After the final delivery, the courier returns to (0,0). Compute the total distance travelled. Visiting a repeated location adds zero for that leg.

## Input format

Line 1: n. The next n lines each contain x and y.

## Output format

Print the total route distance.

## Constraints

1 &lt;= n &lt;= 100000; -1000000000 &lt;= x,y &lt;= 1000000000. The total may require a 64-bit integer.

## Example 1

**Input**

```text
3
2 1
-1 1
-1 -2
```

**Output**

```text
12
```

## Example 2

**Input**

```text
1
3 -4
```

**Output**

```text
14
```

## Answer

Use the following algorithm to produce the result for any input that satisfies the question rules.

## Explanation

Remember the previous coordinates, beginning at the origin. Add abs(dx)+abs(dy) for each visit, then add the distance from the final point back to the origin.

O(n) time; O(1) extra working space with streaming points.

Do not use Euclidean distance or forget the return leg. Use Java long for totals and coordinate differences.
