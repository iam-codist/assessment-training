# Choose semantic HTML for navigation

## Question

Which element best represents a major set of site navigation links?

A. nav
B. A div with no other semantics
C. A span around each letter
D. br

<details>
<summary>Show answer and explanation</summary>

## Answer

A. nav.

## Explanation

A nav landmark gives assistive technology and readers a meaningful navigation region. Use anchor elements for links. Semantic elements describe purpose; CSS can then control appearance without replacing that meaning.
