# Boolean evaluation

## Question

Given x = 4 and y = 9, evaluate (x \> 4 OR y = 9) AND x \< y.

## Options

| Option | Answer choice |
| --- | --- |
| A | False |
| B | 9 |
| C | 4 |
| D | True |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. True

## Explanation

The OR expression is true because y = 9. The comparison 4 \< 9 is also true.

</details>
