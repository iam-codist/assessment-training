# Even or odd branch

## Question

For x = 7, what does IF x MOD 2 = 0 PRINT "A" ELSE PRINT "B" produce?

## Options

| Option | Answer choice |
| --- | --- |
| A | A |
| B | 0 |
| C | B |
| D | 1 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. B

## Explanation

7 MOD 2 is 1, so the ELSE branch runs.
