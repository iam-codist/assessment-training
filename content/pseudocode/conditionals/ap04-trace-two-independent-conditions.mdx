# Trace two independent conditions

## Question

Start with x = 4. If x is even, add 3. Then independently, if x is greater than 6, double it. What is x?

## Options

| Option | Answer choice |
| --- | --- |
| A | 4 |
| B | 7 |
| C | 8 |
| D | 14 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 14

## Explanation

The first condition makes x equal to 7. The second uses the updated value and doubles it.
