# Conditional warm-up

## Question

What is printed by this pseudocode?

```text
INTEGER a = 10, b = 20, c = 5
IF a + c > b THEN
    PRINT a
ELSE IF b - c > a THEN
    PRINT b
ELSE
    PRINT c
END IF
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 10 |
| B | 20 |
| C | 5 |
| D | 15 |

## Notes

Pseudocode warm-up.

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 20

## Explanation

15 > 20 is false; 15 > 10 is true, so print b.
