# Else-if branch

## Question

x=5; IF x\<3: PRINT "low"; ELSE IF x\<7: PRINT "mid"; ELSE: PRINT "high". Output?

## Options

| Option | Answer choice |
| --- | --- |
| A | mid |
| B | low |
| C | high |
| D | Nothing |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. mid

## Explanation

The first condition fails and the second succeeds.
