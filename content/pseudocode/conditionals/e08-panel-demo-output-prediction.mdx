# Panel demo output prediction

## Question

What is printed by this pseudocode?

```text
a = 2
b = 5
FOR i = 1 TO 3
    a = a + i
    IF a MOD 2 == 0 THEN
        b = b - a
    ELSE
        b = b + i
    END IF
END FOR
PRINT a, b
```

<summary>Show answer and explanation</summary>

## Answer

8 0

## Explanation
