# Sequential assignment

## Question

What is printed?

```text
a <- 4
b <- 7
a <- a + b
b <- a - b
PRINT a, b
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 4 7 |
| B | 11 4 |
| C | 11 7 |
| D | 7 4 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 11 4

## Explanation

After a becomes 11, b uses that updated value: 11-7=4. Assignment is sequential.

</details>
