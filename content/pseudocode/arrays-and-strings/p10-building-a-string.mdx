# Building a string

## Question

What is printed?

```text
s <- "abcd"
t <- ""
FOR i <- 0 TO 3
    t <- s[i] + t
END FOR
PRINT t
```

## Options

| Option | Answer choice |
| --- | --- |
| A | abcd |
| B | badc |
| C | dcba |
| D | dabc |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. dcba

## Explanation

Each character is added before the existing t. The successive strings are a, ba, cba, dcba.
