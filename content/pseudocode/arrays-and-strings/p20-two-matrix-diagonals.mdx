# Two matrix diagonals

## Question

What is printed?

```text
M <- [[2, 1, 4], [3, 5, 0], [7, 8, 6]]
s <- 0
FOR i <- 0 TO 2
    s <- s + M[i][i] - M[i][2 - i]
END FOR
PRINT s
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 3 |
| B | -5 |
| C | 0 |
| D | -3 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. -3

## Explanation

The diagonal sums are 2+5+6=13 and 4+5+7=16. Their difference is -3; the shared center cancels.
