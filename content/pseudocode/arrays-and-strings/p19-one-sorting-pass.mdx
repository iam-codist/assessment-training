# One sorting pass

## Question

What is printed?

```text
A <- [5, 1, 4, 2]
FOR i <- 0 TO 2
    IF A[i] > A[i + 1] THEN
        SWAP(A[i], A[i + 1])
    END IF
END FOR
PRINT A
```

## Options

| Option | Answer choice |
| --- | --- |
| A | [1, 4, 2, 5] |
| B | [1, 2, 4, 5] |
| C | [5, 1, 2, 4] |
| D | [1, 5, 2, 4] |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. [1, 4, 2, 5]

## Explanation

The adjacent swaps move 5 rightward: [1,5,4,2], [1,4,5,2], [1,4,2,5]. One pass does not sort the whole array.
