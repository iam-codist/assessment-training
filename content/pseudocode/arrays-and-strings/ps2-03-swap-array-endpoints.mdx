# Swap array endpoints

## Question

A=[2,7,4]; swap A[0] and A[2]. What is A?

## Options

| Option | Answer choice |
| --- | --- |
| A | [7,4,2] |
| B | [2,4,7] |
| C | [2,7,4] |
| D | [4,7,2] |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. [4,7,2]

## Explanation

The first and last items exchange places.
