# Array Manipulation

## Question

What is printed by this pseudocode?

```text
arr = [3, 6, 9, 12, 15]

FOR i = 1 TO 4
    arr[i] = arr[i] - arr[i-1]
END FOR

PRINT arr[4]
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 3 |
| B | 6 |
| C | 9 |
| D | 12 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 9

## Explanation

Updated array: [3,3,6,6,9]. Each step uses the changed previous element.
