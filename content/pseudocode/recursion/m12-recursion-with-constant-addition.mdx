# Recursion with Constant Addition

## Question

What is printed by this pseudocode?

```text
FUNCTION calc(n)
    IF n == 0 THEN
        RETURN 0
    END IF

    RETURN 2 + calc(n-1)
END FUNCTION

PRINT calc(5)
```
