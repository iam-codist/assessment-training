# Swap with a temporary variable

## Question

x=5; y=9; t=x; x=y; y=t. Final (x,y)?

## Options

| Option | Answer choice |
| --- | --- |
| A | (9,5) |
| B | (9,9) |
| C | (5,5) |
| D | (5,9) |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. (9,5)

## Explanation

The temporary variable preserves the original x during the swap.
