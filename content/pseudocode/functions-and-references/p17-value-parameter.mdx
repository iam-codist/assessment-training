# Value parameter

## Question

What is printed?

```text
FUNCTION CHANGE(x)
    x <- x + 10
    RETURN x
END FUNCTION
a <- 5
b <- CHANGE(a)
PRINT a, b
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 15 15 |
| B | 5 15 |
| C | 5 5 |
| D | 15 5 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 5 15

## Explanation

The function changes its local scalar x and returns 15. The caller variable a remains 5.
