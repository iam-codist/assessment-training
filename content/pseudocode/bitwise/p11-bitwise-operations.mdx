# Bitwise operations

## Question

What is printed?

```text
a <- 10
b <- 12
c <- (a BITAND b) BITXOR 3
PRINT c
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 11 |
| B | 5 |
| C | 8 |
| D | 15 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 11

## Explanation

10 is 1010 in binary and 12 is 1100. BITAND gives 1000 (8); XOR with 0011 gives 1011 (11).
