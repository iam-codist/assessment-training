# Bitwise challenge with 6 and 3

## Question

What is printed by this pseudocode?

```text
INTEGER a = 6, b = 3
INTEGER c = (a AND b) + (a XOR b)
PRINT c
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 5 |
| B | 7 |
| C | 9 |
| D | 11 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 7

## Explanation

6 AND 3 = 2 and 6 XOR 3 = 5. Sum = 7, also 6 OR 3.
