# Bit shifting

## Question

What is printed?

```text
x <- 7
x <- x SHL 2
x <- x SHR 1
PRINT x
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 7 |
| B | 28 |
| C | 3 |
| D | 14 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 14

## Explanation

7 shifted left by two places is 28; shifting that right by one gives 14.
