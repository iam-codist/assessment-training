# Skipping an iteration

## Question

s=0; FOR EACH v IN [2,4,1]: IF v=4: CONTINUE; s=s+v. Final s?

## Options

| Option | Answer choice |
| --- | --- |
| A | 2 |
| B | 3 |
| C | 7 |
| D | 6 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 3

## Explanation

CONTINUE skips the rest of the iteration for 4.
