# Trace continue and break

## Question

Set total to 0. For i from 1 to 6 inclusive: skip the iteration if i is even, stop the loop if i is 5, otherwise add i. What is total?

## Options

| Option | Answer choice |
| --- | --- |
| A | 9 |
| B | 4 |
| C | 15 |
| D | 6 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 4

## Explanation

The loop adds 1 and 3, skips 2 and 4, and stops before adding 5.
