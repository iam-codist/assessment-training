# Integer division loop

## Question

n = 20; c = 0; WHILE n \> 3: n = n DIV 2; c = c + 1. What is c?

## Options

| Option | Answer choice |
| --- | --- |
| A | 2 |
| B | 4 |
| C | 5 |
| D | 3 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 3

## Explanation

The updates are 20 → 10 → 5 → 2. The condition fails after update three.
