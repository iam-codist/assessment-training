# Rectangular nested loop

## Question

x=0; FOR i=1 TO 3: FOR j=1 TO 2: x=x+1. Final x?

## Options

| Option | Answer choice |
| --- | --- |
| A | 5 |
| B | 6 |
| C | 3 |
| D | 9 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 6

## Explanation

Three outer iterations each run two inner iterations.
