# Nested loop variant adding i

## Question

What is printed by this pseudocode?

```text
INTEGER sum = 0
FOR i = 1 TO 4
    FOR j = 1 TO i
        sum = sum + i
    END FOR
END FOR
PRINT sum
```

<details>
<summary>Show answer and explanation</summary>

## Answer

30

## Explanation

Each i is added i times: 1² + 2² + 3² + 4² = 30. This differs from M01, whose output is 20.
