# Dividing until odd

## Question

n=24; c=0; WHILE n MOD 2=0: n=n DIV 2; c=c+1. What is c?

## Options

| Option | Answer choice |
| --- | --- |
| A | 4 |
| B | 3 |
| C | 2 |
| D | 1 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 3

## Explanation

The values are 24, 12, 6, and 3. The loop stops at the first odd value.
