# Loop accumulation

## Question

x = 2; FOR i FROM 1 TO 3: x = x + i. What is x?

## Options

| Option | Answer choice |
| --- | --- |
| A | 5 |
| B | 8 |
| C | 6 |
| D | 9 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 8

## Explanation

The loop adds 1, 2, and 3 to the starting value 2.
