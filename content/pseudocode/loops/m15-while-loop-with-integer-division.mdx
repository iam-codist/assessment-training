# WHILE Loop with Integer Division

## Question

What is printed by this pseudocode?

```text
INTEGER x = 100, steps = 0

WHILE x > 5
    x = x DIV 2
    steps = steps + 1
END WHILE

PRINT steps
```

| Option | Answer choice |
| --- | --- |
| A | 4 |
| B | 5 |
| C | 6 |
| D | 7 |

## Answer

B. 5

## Explanation

x becomes 50,25,12,6,3: five divisions.
