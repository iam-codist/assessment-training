# Post-test loop

## Question

x=2; REPEAT: x=x-1 UNTIL x=0. How many iterations run?

## Options

| Option | Answer choice |
| --- | --- |
| A | 0 |
| B | 1 |
| C | 3 |
| D | 2 |

<details>
<summary>Show answer and explanation</summary>

## Answer

## Explanation
