# Nested loop count

## Question

FOR i FROM 1 TO 3, run an inner loop FOR j FROM 1 TO i that prints "\*". How many stars are printed?

## Options

| Option | Answer choice |
| --- | --- |
| A | 3 |
| B | 6 |
| C | 9 |
| D | 4 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 6

## Explanation

The inner loop runs 1, 2, and 3 times on successive outer iterations.
