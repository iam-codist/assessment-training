# Nested loop count

## Question

What is printed?

```text
count <- 0
FOR i <- 1 TO 4
    FOR j <- 1 TO i
        count <- count + 1
    END FOR
END FOR
PRINT count
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 8 |
| B | 10 |
| C | 16 |
| D | 6 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 10

## Explanation

The inner-loop counts are 1,2,3,4, so the total is 10.
