# Break in a loop

## Question

s = 0; FOR EACH v IN [3, 0, 8]: IF v = 0 BREAK; s = s + v. What is s?

## Options

| Option | Answer choice |
| --- | --- |
| A | 11 |
| B | 3 |
| C | 8 |
| D | 0 |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 3

## Explanation

The loop adds 3, then exits at 0 before reaching 8.
