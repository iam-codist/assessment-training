# Early loop exit

## Question

What is printed?

```text
s <- 0
FOR i <- 1 TO 10
    s <- s + i
    IF s > 12 THEN
        BREAK
    END IF
END FOR
PRINT i, s
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 5 15 |
| B | 4 10 |
| C | 6 21 |
| D | 10 55 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 5 15

## Explanation

After adding 5, the running sum is 15 and exceeds 12. The loop exits with i=5.
