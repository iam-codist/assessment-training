# Mixed values · 14

## Question

Pop in ASCENDING order (smallest → largest).

| Bubble | Expression / number |
| --- | --- |
| A | 0.4 |
| B | 3/4 |
| C | 3/5 |
| D | 0.7 |
| E | 90% |
| F | 1/2 |

<details>
<summary>Show answer and explanation</summary>

## Answer

0.4 → 1/2 → 3/5 → 0.7 → 3/4 → 90%

## Explanation

Correct order: 0.4 → 1/2 → 3/5 → 0.7 → 3/4 → 90%.
Evaluate each expression first, then compare the values in the direction requested.
