# Fractions · 13

## Question

Pop in DESCENDING order (largest → smallest).

| Bubble | Expression / number |
| --- | --- |
| A | 1/4 |
| B | 3/8 |
| C | 2/3 |
| D | 5/8 |
| E | 1/5 |
| F | 3/4 |

<details>
<summary>Show answer and explanation</summary>

## Answer

3/4 → 2/3 → 5/8 → 3/8 → 1/4 → 1/5

## Explanation

Correct order: 3/4 → 2/3 → 5/8 → 3/8 → 1/4 → 1/5.
Evaluate each expression first, then compare the values in the direction requested.
