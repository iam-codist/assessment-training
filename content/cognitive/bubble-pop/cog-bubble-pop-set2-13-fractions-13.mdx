# Fractions · 13

## Question

Pop in DESCENDING order (largest → smallest).

| Bubble | Expression / number |
| --- | --- |
| A | 1/5 |
| B | 1/3 |
| C | 2/4 |
| D | 2/3 |
| E | 5/8 |
| F | 7/8 |

<details>
<summary>Show answer and explanation</summary>

## Answer

7/8 → 2/3 → 5/8 → 2/4 → 1/3 → 1/5

## Explanation

Correct order: 7/8 → 2/3 → 5/8 → 2/4 → 1/3 → 1/5.
Evaluate each expression before comparing the values. Multiplication comes before addition or subtraction.

| --- | --- |
| 1/5 | 0.2 |
| 1/3 | 0.333333 |
| 2/4 | 0.5 |
| 2/3 | 0.666667 |
