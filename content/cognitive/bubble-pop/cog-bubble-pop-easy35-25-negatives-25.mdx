| Bubble | Expression / number |
| --- | --- |
| A | 8−10 |
| B | 8−7 |
| C | 5−11 |
| D | 6−6 |
| E | 11−6 |

## Answer

## Explanation

Correct order: 11−6 → 5−1 → 8−7 → 6−6 → 2−3 → 8−10 → 5−11.
