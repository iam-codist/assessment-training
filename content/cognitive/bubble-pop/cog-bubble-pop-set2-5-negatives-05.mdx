# Negatives · 05

## Question

Pop in ASCENDING order (smallest → largest).

| Bubble | Expression / number |
| --- | --- |
| A | −14 |
| B | −1 |
| C | −16 |
| D | 6 |
| E | 0 |

<details>
<summary>Show answer and explanation</summary>

## Answer

−16 → −14 → −1 → 0 → 6

## Explanation

Correct order: −16 → −14 → −1 → 0 → 6.
Evaluate each expression before comparing the values. Multiplication comes before addition or subtraction.

| Expression / number | Value |
| --- | --- |
| −14 | -14 |
| −1 | -1 |
| −16 | -16 |
| 6 | 6 |
| 0 | 0 |
