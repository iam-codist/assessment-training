# Expressions · 28

## Question

Pop in ASCENDING order (smallest → largest).

| Bubble | Expression / number |
| --- | --- |
| A | 6×9−1 |
| B | 6×8−1 |
| C | 4×6−8 |
| D | 3×10+6 |
| E | 2×11−8 |
| F | 4×3−6 |
| G | 9×7+4 |

## Answer

4×3−6 → 2×11−8 → 4×6−8 → 3×10+6 → 6×8−1 → 6×9−1 → 9×7+4

## Explanation

Correct order: 4×3−6 → 2×11−8 → 4×6−8 → 3×10+6 → 6×8−1 → 6×9−1 → 9×7+4.
Evaluate each expression before comparing the values. Multiplication comes before addition or subtraction.
