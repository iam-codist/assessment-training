# Mixed values · 14

## Question

Pop in DESCENDING order (largest → smallest).

| Bubble | Expression / number |
| --- | --- |
| A | 3/10 |
| B | 2/5 |
| C | 0.9 |
| D | 3/4 |
| E | 1/2 |
| F | 1/5 |

<details>
<summary>Show answer and explanation</summary>

## Answer

0.9 → 3/4 → 1/2 → 2/5 → 3/10 → 1/5

## Explanation

Correct order: 0.9 → 3/4 → 1/2 → 2/5 → 3/10 → 1/5.
Evaluate each expression before comparing the values. Multiplication comes before addition or subtraction.
