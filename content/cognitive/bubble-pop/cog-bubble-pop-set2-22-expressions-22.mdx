# Expressions · 22

## Question

Pop in ASCENDING order (smallest → largest).

| Bubble | Expression / number |
| --- | --- |
| A | 7×12+9 |
| B | 3×7+2 |
| C | 6×5−4 |
| D | 2×2−4 |
| E | 4×5+5 |
| F | 8×12+9 |
| G | 6×2+4 |

## Answer

2×2−4 → 6×2+4 → 3×7+2 → 4×5+5 → 6×5−4 → 7×12+9 → 8×12+9

## Explanation

Correct order: 2×2−4 → 6×2+4 → 3×7+2 → 4×5+5 → 6×5−4 → 7×12+9 → 8×12+9.
Evaluate each expression before comparing the values. Multiplication comes before addition or subtraction.
