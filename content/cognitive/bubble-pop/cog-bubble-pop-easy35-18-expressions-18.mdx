| Bubble | Expression / number |
| --- | --- |
| A | 2×4−3 |
| B | 7×3−3 |
| C | 8×9−2 |
| D | 8×10−3 |
| E | 2×2−9 |

## Answer

2×2−9 → 2×4−3 → 7×3−3 → 8×9−2 → 9×7+10 → 8×10−3

## Explanation

Correct order: 2×2−9 → 2×4−3 → 7×3−3 → 8×9−2 → 9×7+10 → 8×10−3.
