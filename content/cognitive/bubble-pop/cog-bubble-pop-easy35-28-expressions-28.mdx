# Expressions · 28

Pop in DESCENDING order (largest → smallest).

| Bubble | Expression / number |
| --- | --- |
| A | 4×3−2 |
| B | 6×5+4 |
| C | 7×8+7 |
| D | 6×3+2 |

| F | 6×3+4 |

## Answer

7×8+7 → 7×8−8 → 4×12−2 → 6×5+4 → 6×3+4 → 6×3+2 → 4×3−2

## Explanation

Correct order: 7×8+7 → 7×8−8 → 4×12−2 → 6×5+4 → 6×3+4 → 6×3+2 → 4×3−2.
