# Expressions · 22

## Question

Pop in DESCENDING order (largest → smallest).

| Bubble | Expression / number |
| --- | --- |
| A | 2×6+8 |
| B | 5×3+1 |
| C | 4×8−8 |
| D | 9×3+2 |
| E | 4×12+4 |
| F | 8×4−1 |

## Answer

4×12+4 → 8×4−1 → 9×3+2 → 4×8−8 → 2×6+8 → 5×3+1

## Explanation

Correct order: 4×12+4 → 8×4−1 → 9×3+2 → 4×8−8 → 2×6+8 → 5×3+1.
