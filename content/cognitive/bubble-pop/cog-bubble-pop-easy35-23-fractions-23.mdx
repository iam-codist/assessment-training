| Bubble | Expression / number |
| --- | --- |
| A | 1/8 |
| B | 2/3 |
| C | 3/5 |
| D | 1/3 |
| E | 3/4 |

## Answer

## Explanation

Correct order: 1/8 → 1/3 → 2/4 → 3/5 → 2/3 → 3/4.
