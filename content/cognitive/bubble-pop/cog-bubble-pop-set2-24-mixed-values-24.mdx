# Mixed values · 24

## Question

Pop in DESCENDING order (largest → smallest).

| Bubble | Expression / number |
| --- | --- |
| A | 0.9 |
| B | 0.2 |
| C | 0.4 |
| D | 8/10 |
| E | 3/5 |
| F | 10% |
| G | 75% |

<summary>Show answer and explanation</summary>

## Answer

0.9 → 8/10 → 75% → 3/5 → 0.4 → 0.2 → 10%

## Explanation

Correct order: 0.9 → 8/10 → 75% → 3/5 → 0.4 → 0.2 → 10%.
Evaluate each expression before comparing the values. Multiplication comes before addition or subtraction.
