# Expressions · 12

## Question

Pop in DESCENDING order (largest → smallest).

| Bubble | Expression / number |
| --- | --- |
| A | 5×9+3 |
| B | 6×5+6 |
| C | 5×5+4 |
| D | 8×7−3 |
| E | 7×2+9 |
| F | 3×6+7 |

<details>
<summary>Show answer and explanation</summary>

## Answer

8×7−3 → 5×9+3 → 6×5+6 → 5×5+4 → 3×6+7 → 7×2+9

## Explanation

Correct order: 8×7−3 → 5×9+3 → 6×5+6 → 5×5+4 → 3×6+7 → 7×2+9.
Evaluate each expression before comparing the values. Multiplication comes before addition or subtraction.
