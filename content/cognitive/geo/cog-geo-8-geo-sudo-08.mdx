# Geo-Sudo 08

## Question

Every row and column must contain each shape exactly once. Which shape belongs in the highlighted cell? There are no smaller box rules.

| Row / Col | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 1 | Cross | · | Square | · |
| 2 | Square | · | · | Circle |
| 3 | · | Square | · | · |
| 4 | · | Cross | · | **?** |

Target: row 4, column 4. A dot is an empty cell. Only row and column rules apply.

## Options

| Option | Answer choice |
| --- | --- |
| A | Circle |
| B | Cross |
| C | Triangle |
| D | Square |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Square

## Explanation

The missing shape is square. Checking every valid row-and-column completion gives the same shape in the highlighted cell.
There are 2 valid completions of this board. Explain which row or column eliminates each alternative.
