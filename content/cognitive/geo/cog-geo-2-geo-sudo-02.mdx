# Geo-Sudo 02

## Question

Every row and column must contain each shape exactly once. Which shape belongs in the highlighted cell? There are no smaller box rules.

| Row / Col | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 1 | · | · | Cross | · |
| 2 | Cross | **?** | Square | Circle |
| 3 | · | · | Triangle | · |
| 4 | · | · | Circle | · |

Target: row 2, column 2. A dot is an empty cell. Only row and column rules apply.

## Options

| Option | Answer choice |
| --- | --- |
| A | Circle |
| B | Cross |
| C | Triangle |
| D | Square |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Triangle

## Explanation

The missing shape is triangle. Checking every valid row-and-column completion gives the same shape in the highlighted cell.
There are 4 valid completions of this board. Explain which row or column eliminates each alternative.
