# Growing gaps

## Question

Find the missing number using the simplest consistent pattern. Explain the step between terms.

```text
2 → 5 → 10 → 17 → ? → 37
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 24 |
| B | 25 |
| C | 26 |
| D | 28 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 26

## Explanation

The gaps are +3, +5, +7, +9, +11. Add 9 to 17 to get 26.
