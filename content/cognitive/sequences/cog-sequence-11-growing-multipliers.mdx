# Growing multipliers

## Question

Find the missing number using the simplest consistent pattern. Explain the step between terms.

```text
1 → 2 → 6 → 24 → ? → 720
```

## Options

| Option | Answer choice |
| --- | --- |
| A | 48 |
| B | 96 |
| C | 120 |
| D | 144 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 120

## Explanation

Multiply successively by 2, 3, 4, 5, 6. 24 × 5 = 120; 120 × 6 = 720.

</details>
