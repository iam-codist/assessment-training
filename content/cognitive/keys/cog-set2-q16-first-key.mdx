# First Key

## Question

Entering a room picks up its key. A coloured bar is a locked door needing that colour of key (keys are reusable); thin grey links are open. On the shortest route from START to EXIT, which key is picked up first?

| Row / Col | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 1 | A | B | C |
| 2 | D | E | F |
| 3 | G | H | I |

Start: **A**. Exit: **I**. Keys: C: B, D: G, H: R. R = red; G = green; B = blue.

Only the following links exist. Each move uses one link, in either direction.

| Rooms connected | Required key |
| --- | --- |
| A ↔ B | Open |
| A ↔ D | Open |
| B ↔ C | R |
| B ↔ E | Open |
| C ↔ F | Open |
| D ↔ E | R |
| D ↔ G | Open |
| E ↔ F | Open |
| E ↔ H | Open |
| F ↔ I | B |
| G ↔ H | B |
| H ↔ I | B |

## Options

| Option | Answer choice |
| --- | --- |
| A | Blue key |
| B | Green key |
| C | Red key |
| D | No key is needed |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Blue key

## Explanation

Shortest route (6 moves): A > B > E > F > C > F > I.

Keys picked up, in order: Blue key in C.

The first one is the Blue key, collected before any locked door blocks the way.
