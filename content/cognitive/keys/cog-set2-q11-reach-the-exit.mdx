# Reach the Exit

## Question

Entering a room picks up its key. A coloured bar is a locked door needing that colour of key (keys are reusable); thin grey links are open. What is the minimum number of moves (room to room) to get from START to EXIT?

| Row / Col | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 1 | A | B | C |
| 2 | D | E | F |
| 3 | G | H | I |

Start: **F**. Exit: **A**. Keys: B: R, C: B, H: G. R = red; G = green; B = blue.

Only the following links exist. Each move uses one link, in either direction.

| Rooms connected | Required key |
| --- | --- |
| A ↔ B | B |
| A ↔ D | R |
| B ↔ C | R |
| B ↔ E | G |
| C ↔ F | Open |
| D ↔ E | Open |
| D ↔ G | G |
| E ↔ F | Open |
| E ↔ H | Open |
| F ↔ I | R |
| G ↔ H | G |
| H ↔ I | R |

## Options

| Option | Answer choice |
| --- | --- |
| A | 9 moves |
| B | 5 moves |
| C | 4 moves |
| D | 7 moves |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 7 moves

## Explanation

Shortest route (7 moves): F > E > H > E > B > E > D > A.

Keys picked up on the way: Green key in H, Red key in B.

Locked doors crossed: E-B (Green), B-E (Green), D-A (Red).

</details>
