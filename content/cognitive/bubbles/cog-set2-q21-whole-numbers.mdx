# Whole Numbers

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order (smallest first). Which bubble is popped 3rd?

| Bubble | Expression / number |
| --- | --- |
| A | 64 |
| B | 19 |
| C | 92 |
| D | 37 |
| E | 55 |
| F | 8 |
| G | 76 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 19 |
| B | 55 |
| C | 37 |
| D | 64 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 37

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 37.

| Expression / number | Value |
| --- | --- |
| 64 | 64 |
| 19 | 19 |
| 92 | 92 |
| 37 | 37 |
| 55 | 55 |
| 8 | 8 |
| 76 | 76 |

**Eligible pop order:** 8 → 19 → 37 → 55 → 64 → 76 → 92.
