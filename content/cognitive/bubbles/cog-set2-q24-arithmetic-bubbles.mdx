# Arithmetic Bubbles

## Question

Bubbles with the values shown float on the screen. Each shows an expression. Pop them in ASCENDING order of value. Which bubble is popped 4th?

| Bubble | Expression / number |
| --- | --- |
| A | 9 x 8 |
| B | 96 / 8 |
| C | 27 + 38 |
| D | 100 - 23 |
| E | 7² |
| F | 4 x 13 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 27 + 38 |
| B | 96 / 8 |
| C | 100 - 23 |
| D | 4 x 13 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 27 + 38

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 27 + 38.

| Expression / number | Value |
| --- | --- |
| 9 x 8 | 72 |
| 96 / 8 | 12 |
| 27 + 38 | 65 |
| 100 - 23 | 77 |
| 7² | 49 |
| 4 x 13 | 52 |

**Eligible pop order:** 96 / 8 → 7² → 4 x 13 → 27 + 38 → 9 x 8 → 100 - 23.
