# Descending Order

## Question

Bubbles with the values shown float on the screen. Pop them in DESCENDING order (largest first). Which bubble is popped 4th?

| Bubble | Expression / number |
| --- | --- |
| A | 212 |
| B | 175 |
| C | 98 |
| D | 240 |
| E | 133 |
| F | 160 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 240 |
| B | 98 |
| C | 160 |
| D | 133 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 160

## Explanation

Convert every bubble to a plain number first.

Sort the values in descending (largest first) order.

The answer is 160.

| Expression / number | Value |
| --- | --- |
| 212 | 212 |
| 175 | 175 |
| 98 | 98 |
| 240 | 240 |
| 133 | 133 |
| 160 | 160 |

**Eligible pop order:** 240 → 212 → 175 → 160 → 133 → 98.
