# Decimal Trap

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order. Which bubble is popped 2nd?

| Bubble | Expression / number |
| --- | --- |
| A | 0.35 |
| B | 0.305 |
| C | 0.5 |
| D | 0.053 |
| E | 0.4 |
| F | 0.31 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 0.35 |
| B | 0.4 |
| C | 0.305 |
| D | 0.31 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 0.305

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 0.305.

| Expression / number | Value |
| --- | --- |
| 0.35 | 0.35 |
| 0.305 | 0.305 |
| 0.5 | 0.5 |
| 0.053 | 0.053 |
| 0.4 | 0.4 |
| 0.31 | 0.31 |

**Eligible pop order:** 0.053 → 0.305 → 0.31 → 0.35 → 0.4 → 0.5.
