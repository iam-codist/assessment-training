# Descending Order

## Question

Bubbles with the values shown float on the screen. Pop them in DESCENDING order (largest first). Which bubble is popped 2nd?

| Bubble | Expression / number |
| --- | --- |
| A | 156 |
| B | 98 |
| C | 203 |
| D | 87 |
| E | 145 |
| F | 120 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 145 |
| B | 120 |
| C | 156 |
| D | 98 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 156

## Explanation

Convert every bubble to a plain number first.

Sort the values in descending (largest first) order.

The answer is 156.

| Expression / number | Value |
| --- | --- |
| 156 | 156 |
| 98 | 98 |
| 203 | 203 |
| 87 | 87 |
| 145 | 145 |
| 120 | 120 |

**Eligible pop order:** 203 → 156 → 145 → 120 → 98 → 87.
