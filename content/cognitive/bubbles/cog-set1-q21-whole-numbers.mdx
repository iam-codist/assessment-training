# Whole Numbers

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order (smallest first). Which bubble is popped 4th?

| Bubble | Expression / number |
| --- | --- |
| A | 47 |
| B | 12 |
| C | 85 |
| D | 29 |
| E | 63 |
| F | 8 |
| G | 71 |

## Options

| Option | Answer choice |
| --- | --- |
| A | 12 |
| B | 63 |
| C | 29 |
| D | 47 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 47

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 47.

| Expression / number | Value |
| --- | --- |
| 47 | 47 |
| 12 | 12 |
| 85 | 85 |
| 29 | 29 |
| 63 | 63 |
| 8 | 8 |
| 71 | 71 |

**Eligible pop order:** 8 → 12 → 29 → 47 → 63 → 71 → 85.
