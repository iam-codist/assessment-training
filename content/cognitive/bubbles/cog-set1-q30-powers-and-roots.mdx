# Powers and Roots

## Question

Bubbles with the values shown float on the screen. Pop them in ASCENDING order of value. Which bubble is popped immediately BEFORE 5²?

| Bubble | Expression / number |
| --- | --- |
| A | √81 |
| B | 2³ |
| C | 5² |
| D | 3³ |
| E | √144 |
| F | 4² |

## Options

| Option | Answer choice |
| --- | --- |
| A | 3³ |
| B | 4² |
| C | 2³ |
| D | 5² |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. 4²

## Explanation

Convert every bubble to a plain number first.

Sort the values in ascending (smallest first) order.

The answer is 4².

| Expression / number | Value |
| --- | --- |
| √81 | 9 |
| 2³ | 8 |
| 5² | 25 |
| 3³ | 27 |
| √144 | 12 |
| 4² | 16 |

**Eligible pop order:** 2³ → √81 → √144 → 4² → 5² → 3³.
