# Ask a useful clarification question

## Question

A task says: “Find the second largest number.” What should you clarify before coding?

<details>
<summary>Show answer and explanation</summary>

## Answer

Ask whether “second largest” means the second distinct value, and what to return when fewer than two distinct values exist.

## Explanation

For [5,5,3], the second position in descending order is 5 but the second distinct value is 3. A good clarification identifies an ambiguity and gives a concrete example. Also confirm input limits and whether the input may be changed if your solution sorts it.
