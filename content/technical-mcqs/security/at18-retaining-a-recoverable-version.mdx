# Retaining a recoverable version

## Question

A compromised account deletes the current copy and its synchronized copy. What improves recovery?

## Options

| Option | Answer choice |
| --- | --- |
| A | Rename the shared folder |
| B | Keep tested backups protected from modification by that account |
| C | Use the same account for backup administration |
| D | Disable restore testing |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Keep tested backups protected from modification by that account

## Explanation

A protected backup can retain an earlier copy even when the live account can delete synchronized files.
