# Suspicious messages

## Question

An unexpected payroll email asks you to enter your password on a look-alike website to avoid account closure. What is the best immediate response?

## Options

| Option | Answer choice |
| --- | --- |
| A | Enter the password to see whether the page works. |
| B | Report the message through the approved channel and verify the request independently. |
| C | Forward the link to all coworkers and ask them to try it. |
| D | Reply with the password instead of using the link. |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Report the message through the approved channel and verify the request independently.

## Explanation

The urgency and look-alike sign-in page are phishing warning signs. Use the approved reporting route and a separately verified contact or site.

</details>
