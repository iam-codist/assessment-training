# Authentication factors

## Question

Which pair uses two different authentication factor categories?

## Options

| Option | Answer choice |
| --- | --- |
| A | A password and a PIN |
| B | Two different passwords |
| C | A password and a registered hardware security key |
| D | A PIN and a security-question answer |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. A password and a registered hardware security key

## Explanation

The password is something you know and the hardware key is something you have. A password plus another password does not add a new factor category.
