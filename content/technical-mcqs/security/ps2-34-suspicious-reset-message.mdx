# Suspicious reset message

## Question

A staff member receives a suspicious password-reset link. Which action is safest?

## Options

| Option | Answer choice |
| --- | --- |
| A | Enter a password to test the link |
| B | Forward it to the whole team |
| C | Open the app directly and report the message |
| D | Reply with a verification code |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Open the app directly and report the message

## Explanation

Navigating independently avoids the suspicious link while reporting supports investigation.
