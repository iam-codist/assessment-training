# Encrypting a lost backup drive

## Question

A backup drive containing staff records is lost. Which control protects the confidentiality of its stored data?

## Options

| Option | Answer choice |
| --- | --- |
| A | Compression |
| B | File naming conventions |
| C | Encryption at rest |
| D | A load balancer |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Encryption at rest

## Explanation

Encryption at rest makes stored data unreadable without the appropriate key.
