# Availability and a service outage

## Question

An outage makes a library reservation system inaccessible for an hour. Which security objective is directly affected?

## Options

| Option | Answer choice |
| --- | --- |
| A | Integrity |
| B | Availability |
| C | Confidentiality |
| D | Authentication |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Availability

## Explanation

Availability concerns access when needed. An outage blocks users even if the records remain accurate and private.
