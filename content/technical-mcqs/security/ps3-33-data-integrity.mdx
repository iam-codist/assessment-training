# Data integrity

## Question

Which security goal is violated when someone secretly changes a student's marks?

## Options

| Option | Answer choice |
| --- | --- |
| A | Availability |
| B | Confidentiality only |
| C | Integrity |
| D | Portability |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Integrity

## Explanation

Integrity concerns the accuracy and protection of data from unauthorized alteration.
