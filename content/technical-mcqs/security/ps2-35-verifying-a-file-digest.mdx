# Verifying a file digest

## Question

What verifies that downloaded bytes match a trusted published digest?

## Options

| Option | Answer choice |
| --- | --- |
| A | Check the filename |
| B | Compare the creation dates |
| C | Compare a cryptographic hash |
| D | Inspect the file icon |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Compare a cryptographic hash

## Explanation

A matching hash checks integrity if the expected digest came from a trusted source.
