# Mutex exclusion

## Question

What does a mutex generally provide?

## Options

| Option | Answer choice |
| --- | --- |
| A | Exclusive access to a critical section |
| B | Automatic data encryption |
| C | Faster disk access |
| D | Virtual address translation |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Exclusive access to a critical section

## Explanation

A mutex makes cooperating threads take turns entering protected code.
