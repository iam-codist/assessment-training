# FIFO job scheduling

## Question

Which data structure serves waiting jobs in arrival order?

## Options

| Option | Answer choice |
| --- | --- |
| A | Queue |
| B | Stack |
| C | Set |
| D | Heap ordered by job size |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Queue

## Explanation

A FIFO queue removes the earliest inserted item first.
