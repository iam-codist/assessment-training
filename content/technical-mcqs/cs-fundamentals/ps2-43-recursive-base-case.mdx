# Recursive base case

## Question

What is the main purpose of a recursive base case?

## Options

| Option | Answer choice |
| --- | --- |
| A | Increase every input |
| B | Create a new thread |
| C | Stop further recursive calls |
| D | Return every intermediate value |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Stop further recursive calls

## Explanation

The base case returns directly and terminates a chain of calls.
