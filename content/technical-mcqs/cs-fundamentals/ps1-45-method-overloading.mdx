# Method overloading

## Question

Which term describes two Java methods in the same class named print, one taking an int and one taking a String?

## Options

| Option | Answer choice |
| --- | --- |
| A | Overriding |
| B | Overloading |
| C | Inheritance |
| D | Encapsulation |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Overloading

## Explanation

Overloads share a method name but have different parameter lists. Overriding replaces an inherited instance method implementation.
