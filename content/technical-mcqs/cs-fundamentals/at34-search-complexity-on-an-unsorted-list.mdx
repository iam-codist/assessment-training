# Search complexity on an unsorted list

## Question

An unsorted list has n values and the target is absent. How many values does linear search examine?

## Options

| Option | Answer choice |
| --- | --- |
| A | n |
| B | 1 |
| C | log₂ n |
| D | 0 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. n

## Explanation

Without ordering, the algorithm must inspect every value before concluding the target is absent.
