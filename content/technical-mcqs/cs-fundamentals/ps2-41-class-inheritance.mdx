# Class inheritance

## Question

Which OOP term means a subclass acquires behavior from a parent class?

## Options

| Option | Answer choice |
| --- | --- |
| A | Aggregation |
| B | Inheritance |
| C | Encapsulation |
| D | Iteration |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Inheritance

## Explanation

Inheritance lets a subclass reuse or specialize inherited members.
