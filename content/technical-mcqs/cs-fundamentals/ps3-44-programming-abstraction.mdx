# Programming abstraction

## Question

Which principle lets a caller use a simple operation while the implementation details stay hidden?

## Options

| Option | Answer choice |
| --- | --- |
| A | Recursion |
| B | Iteration |
| C | Abstraction |
| D | String concatenation |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Abstraction

## Explanation

Abstraction exposes the behavior the caller needs through a simpler interface.
