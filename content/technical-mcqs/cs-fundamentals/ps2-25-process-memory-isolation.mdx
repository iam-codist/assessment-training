# Process memory isolation

## Question

Which OS feature isolates process address spaces?

## Options

| Option | Answer choice |
| --- | --- |
| A | Virtual memory protection |
| B | File compression |
| C | CPU time slicing |
| D | Disk formatting |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Virtual memory protection

## Explanation

Page mappings and permissions restrict access to another process's memory.
