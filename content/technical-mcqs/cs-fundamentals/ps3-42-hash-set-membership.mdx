# Hash set membership

## Question

Which data structure best supports membership checks by key without preserving duplicate entries?

## Options

| Option | Answer choice |
| --- | --- |
| A | Stack |
| B | FIFO queue |
| C | Linked list alone |
| D | Hash set |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Hash set

## Explanation

A hash set stores unique elements and normally supports fast membership tests.
