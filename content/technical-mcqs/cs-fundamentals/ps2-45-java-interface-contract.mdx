# Java interface contract

## Question

Which named construct lets Java classes promise a common set of operations without extending the same implementation class?

## Options

| Option | Answer choice |
| --- | --- |
| A | Constructor |
| B | Package |
| C | Array |
| D | Interface |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Interface

## Explanation

An interface provides a shared contract that unrelated classes can implement.
