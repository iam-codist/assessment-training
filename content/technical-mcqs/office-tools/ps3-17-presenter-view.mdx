# Presenter View

## Question

What lets a presenter see notes and the next slide while the audience sees the current slide?

## Options

| Option | Answer choice |
| --- | --- |
| A | Slide Sorter |
| B | Outline View |
| C | Slide Master |
| D | Presenter View |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Presenter View

## Explanation

Presenter View separates private controls and notes from the audience display.
