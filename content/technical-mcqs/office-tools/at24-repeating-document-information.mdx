# Repeating document information

## Question

An operating manual needs the same document title at the top of every page. Where should it go?

## Options

| Option | Answer choice |
| --- | --- |
| A | Header |
| B | Endnote |
| C | Table caption |
| D | Comment |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Header

## Explanation

The header is designed for recurring content at the top of pages.
