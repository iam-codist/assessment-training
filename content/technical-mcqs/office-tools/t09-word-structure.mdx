# Word structure

## Question

A long report needs an automatic table of contents based on its sections. Which preparation most directly supports that?

## Options

| Option | Answer choice |
| --- | --- |
| A | Make every section title red. |
| B | Use spaces to indent every title. |
| C | Put all titles in text boxes. |
| D | Apply the appropriate built-in heading styles. |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Apply the appropriate built-in heading styles.

## Explanation

Built-in heading styles supply document structure that Word can use for an automatic table of contents.
