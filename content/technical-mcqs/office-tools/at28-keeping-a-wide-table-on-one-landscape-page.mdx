# Keeping a wide table on one landscape page

## Question

A Word report is portrait except for one wide table. What allows that page to have its own orientation between portrait pages?

## Options

| Option | Answer choice |
| --- | --- |
| A | Insert section breaks around the relevant page |
| B | Insert a single line break |
| C | Add a comment to the table |
| D | Use a text highlight |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Insert section breaks around the relevant page

## Explanation

A separate section can have its own page orientation. Section breaks isolate the landscape portion.
