# Automatic contents table

## Question

Which Word feature builds an updatable list of heading titles and page numbers?

## Options

| Option | Answer choice |
| --- | --- |
| A | Mail Merge |
| B | Footnotes |
| C | Automatic table of contents |
| D | Track Changes |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Automatic table of contents

## Explanation

An automatic contents table uses heading levels and can update its page references.
