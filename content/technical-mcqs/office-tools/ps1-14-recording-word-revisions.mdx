# Recording Word revisions

## Question

A reviewer wants edits recorded so the author can accept or reject each change. Which feature should they enable before editing?

## Options

| Option | Answer choice |
| --- | --- |
| A | Word Count |
| B | Read Mode |
| C | Track Changes |
| D | Mail Merge |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Track Changes

## Explanation

Track Changes records revisions and lets the author accept or reject them individually.
