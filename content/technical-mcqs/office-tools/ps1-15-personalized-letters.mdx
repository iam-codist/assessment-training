# Personalized letters

## Question

Which feature generates personalized letters from one template and a spreadsheet of recipients?

## Options

| Option | Answer choice |
| --- | --- |
| A | Mail Merge |
| B | Track Changes |
| C | Page Break |
| D | Format Painter |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Mail Merge

## Explanation

Mail Merge fills template fields from each recipient record.
