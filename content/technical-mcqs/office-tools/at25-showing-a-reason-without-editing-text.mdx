# Showing a reason without editing text

## Question

A reviewer wants to leave a question beside a sentence without changing the sentence. Which Word feature fits?

## Options

| Option | Answer choice |
| --- | --- |
| A | Mail Merge |
| B | Slide Sorter |
| C | Comment |
| D | Page Break |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Comment

## Explanation

A comment attaches feedback to selected document text without editing it.
