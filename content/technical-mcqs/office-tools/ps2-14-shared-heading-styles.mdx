# Shared heading styles

## Question

You want all chapter headings to update when you change their format once. What should you apply?

## Options

| Option | Answer choice |
| --- | --- |
| A | A comment |
| B | A shared heading style |
| C | A page break |
| D | Individual bold formatting |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. A shared heading style

## Explanation

Editing a style updates all text that uses it.
