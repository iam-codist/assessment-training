# PowerPoint consistency

## Question

A presentation uses one slide master. You want to place the same logo in a consistent position across layouts that inherit from it. Which area should you edit?

## Options

| Option | Answer choice |
| --- | --- |
| A | Notes Page |
| B | Slide Master |
| C | Animation Pane |
| D | Reading View |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Slide Master

## Explanation

The slide master and its inherited layouts control shared design elements. The question specifies a single master.
