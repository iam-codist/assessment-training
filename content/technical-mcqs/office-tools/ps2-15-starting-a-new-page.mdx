# Starting a new page

## Question

Which feature forces the next paragraph to start on a new page even after earlier text changes?

## Options

| Option | Answer choice |
| --- | --- |
| A | Repeated blank lines |
| B | Line spacing |
| C | Page break |
| D | Indentation |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Page break

## Explanation

A page break starts a new page at a stable document position.
