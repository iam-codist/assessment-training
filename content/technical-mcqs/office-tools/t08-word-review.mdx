# Word review

## Question

A reviewer must record inserted and deleted text so the author can accept or reject those edits. Which Word feature should be enabled?

## Options

| Option | Answer choice |
| --- | --- |
| A | Track Changes |
| B | Read Mode |
| C | Format Painter |
| D | Find |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Track Changes

## Explanation

Track Changes records insertions and deletions for later acceptance or rejection. A comment alone does not track an edit.
