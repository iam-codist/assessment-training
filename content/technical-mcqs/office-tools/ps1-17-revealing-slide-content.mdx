# Revealing slide content

## Question

You want a bullet list to appear after a click while staying on the same slide. Which feature applies?

## Options

| Option | Answer choice |
| --- | --- |
| A | Slide transition |
| B | Entrance animation |
| C | Slide size |
| D | Slide layout |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Entrance animation

## Explanation

An entrance animation controls when an object appears on a slide. Transitions apply between slides.
