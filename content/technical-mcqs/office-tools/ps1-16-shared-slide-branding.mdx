# Shared slide branding

## Question

Where should you edit a logo intended to appear across slides that use the same master?

## Options

| Option | Answer choice |
| --- | --- |
| A | Notes pane |
| B | Slide Sorter |
| C | Animation Pane |
| D | Slide Master |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Slide Master

## Explanation

The master supplies shared design elements to slides that use it, subject to layout and slide settings.
