# Mixed references when copying

## Question

Cell B2 contains =$A2\*B$1. The formula is copied to C3. What is the result?

## Options

| Option | Answer choice |
| --- | --- |
| A | =$A3\*C$1 |
| B | =$B3\*C$2 |
| C | =$A2\*B$1 |
| D | =A3\*$C1 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. =$A3\*C$1

## Explanation

The A column and row 1 are fixed. The unanchored row 2 and column B shift by one.
