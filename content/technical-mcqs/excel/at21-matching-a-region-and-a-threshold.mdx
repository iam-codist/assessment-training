# Matching a region and a threshold

## Question

A workbook needs a count of rows where region is West and score is at least 60. Which function is designed for multiple criteria ranges?

## Options

| Option | Answer choice |
| --- | --- |
| A | SUM |
| B | COUNTA |
| C | COUNTIFS |
| D | AVERAGE |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. COUNTIFS

## Explanation

COUNTIFS tests each row against multiple conditions and counts the rows satisfying all of them.
