# Numeric cells

## Question

Which Excel function counts numeric cells?

## Options

| Option | Answer choice |
| --- | --- |
| A | COUNTA |
| B | COUNT |
| C | SUM |
| D | COUNTIF |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. COUNT

## Explanation

COUNT counts numeric cells, including zero.
