# Pass or fail formula

## Question

Which formula returns Pass when B2 is at least 60 and Fail otherwise?

## Options

| Option | Answer choice |
| --- | --- |
| A | =IF(B2\<60,"Pass","Fail") |
| B | =COUNTIF(B2,"\>=60") |
| C | =IF(B2\>=60,"Pass","Fail") |
| D | =AND(B2\>=60) |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. =IF(B2\>=60,"Pass","Fail")

## Explanation

IF returns its second argument when the condition is true and its third otherwise.
