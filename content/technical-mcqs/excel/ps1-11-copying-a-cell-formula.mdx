# Copying a cell formula

## Question

C2 contains =B2\*$F$1. What formula results when C2 is copied to C3?

## Options

| Option | Answer choice |
| --- | --- |
| A | =B3\*$F$1 |
| B | =B2\*$F$2 |
| C | =B3\*$F$2 |
| D | =B2\*$F$1 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. =B3\*$F$1

## Explanation

The relative row in B2 moves down one. Both coordinates in $F$1 stay fixed.
