# Drop-down data validation

## Question

Which feature can restrict data entry to a drop-down list of departments?

## Options

| Option | Answer choice |
| --- | --- |
| A | Conditional Formatting |
| B | Data Validation |
| C | Text to Columns |
| D | Sort |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Data Validation

## Explanation

Data Validation can show a list and reject other entries according to its settings.
