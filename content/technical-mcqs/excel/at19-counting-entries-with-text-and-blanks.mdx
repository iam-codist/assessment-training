# Counting entries with text and blanks

## Question

A2:A6 contains 9, a truly blank cell, the text Hold, 0 and 12. What does =COUNT(A2:A6) return?

## Options

| Option | Answer choice |
| --- | --- |
| A | 4 |
| B | 5 |
| C | 2 |
| D | 3 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 3

## Explanation

COUNT includes the numeric cells 9, 0 and 12. It skips the blank and text.
