# Primary key constraints

## Question

Which constraint identifies every row with a unique, non-null key?

## Options

| Option | Answer choice |
| --- | --- |
| A | DEFAULT |
| B | CHECK |
| C | FOREIGN KEY |
| D | PRIMARY KEY |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. PRIMARY KEY

## Explanation

A primary key uniquely identifies a row and its columns cannot contain NULL.
