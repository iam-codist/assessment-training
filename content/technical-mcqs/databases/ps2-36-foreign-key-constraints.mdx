# Foreign key constraints

## Question

What does a foreign key normally enforce?

## Options

| Option | Answer choice |
| --- | --- |
| A | Referenced parent values exist when required |
| B | Rows are sorted alphabetically |
| C | Every column has a default |
| D | Duplicate child values are forbidden |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Referenced parent values exist when required

## Explanation

A foreign key links each non-null reference to a valid parent key for a simple single-column key.
