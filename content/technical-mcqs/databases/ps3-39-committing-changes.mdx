# Committing changes

## Question

Which SQL transaction command makes pending changes permanent?

## Options

| Option | Answer choice |
| --- | --- |
| A | ROLLBACK |
| B | COMMIT |
| C | SELECT |
| D | SAVEPOINT |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. COMMIT

## Explanation

COMMIT finalizes the transaction. ROLLBACK discards its pending changes.

</details>
