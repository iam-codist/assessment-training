# Distinct result rows

## Question

Which clause removes duplicate rows from a SELECT result?

## Options

| Option | Answer choice |
| --- | --- |
| A | ORDER BY |
| B | SELECT DISTINCT |
| C | HAVING |
| D | LIMIT |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. SELECT DISTINCT

## Explanation

DISTINCT keeps one copy of each distinct output row.
