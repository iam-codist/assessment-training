# Testing for SQL NULL

## Question

What does WHERE price IS NULL select?

## Options

| Option | Answer choice |
| --- | --- |
| A | Rows priced at zero |
| B | Rows with negative prices |
| C | Every row |
| D | Rows whose price is missing |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Rows whose price is missing

## Explanation

IS NULL tests for a missing SQL value.
