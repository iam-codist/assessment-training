# Relational normalization

## Question

What is the main purpose of normalization in a relational schema?

## Options

| Option | Answer choice |
| --- | --- |
| A | Encrypt every table |
| B | Sort results by default |
| C | Reduce redundant data and update anomalies |
| D | Store all facts in one table |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Reduce redundant data and update anomalies

## Explanation

Normalization organizes facts by their dependencies to reduce duplication and inconsistent updates.
