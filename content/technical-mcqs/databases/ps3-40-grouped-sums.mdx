# Grouped sums

## Question

What does GROUP BY category typically do with SUM(amount)?

## Options

| Option | Answer choice |
| --- | --- |
| A | Calculates a sum for each category |
| B | Selects only the largest amount |
| C | Deletes repeated categories |
| D | Sorts categories automatically |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. Calculates a sum for each category

## Explanation

GROUP BY forms one group per category and SUM aggregates each group.
