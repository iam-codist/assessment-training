# Datagram transport

## Question

Which transport protocol sends datagrams without built-in delivery guarantees?

## Options

| Option | Answer choice |
| --- | --- |
| A | TCP |
| B | ARP |
| C | TLS |
| D | UDP |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. UDP

## Explanation

UDP provides datagrams without TCP-style acknowledgments or retransmission.
