# Reliable transport

## Question

Which transport protocol provides a reliable, ordered byte stream?

## Options

| Option | Answer choice |
| --- | --- |
| A | TCP |
| B | UDP |
| C | IP |
| D | ARP |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. TCP

## Explanation

TCP uses sequence numbers, acknowledgments, and retransmission to deliver an ordered stream.
