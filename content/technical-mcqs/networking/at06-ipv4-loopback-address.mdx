# IPv4 loopback address

## Question

A developer tests a service bound to 127.0.0.1. Where does a request to that address go?

## Options

| Option | Answer choice |
| --- | --- |
| A | The local machine |
| B | The default gateway |
| C | The public DNS server |
| D | Every device on the LAN |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. The local machine

## Explanation

The IPv4 loopback range directs traffic back to the same host.
