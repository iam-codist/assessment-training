# Network latency

## Question

What is network latency?

## Options

| Option | Answer choice |
| --- | --- |
| A | Maximum data rate |
| B | Total storage capacity |
| C | Number of open applications |
| D | Time taken for data to travel |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Time taken for data to travel

## Explanation

Latency measures delay. Bandwidth measures capacity over time.
