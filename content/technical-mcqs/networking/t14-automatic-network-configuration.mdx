# Automatic network configuration

## Question

A laptop joins a network and automatically receives an IPv4 address, subnet mask, default gateway and DNS server settings. Which protocol normally provides that configuration?

## Options

| Option | Answer choice |
| --- | --- |
| A | SMTP |
| B | DHCP |
| C | FTP |
| D | SNMP |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. DHCP

## Explanation

DHCP can provide a leased IPv4 address plus settings such as a subnet mask, gateway and DNS servers.
