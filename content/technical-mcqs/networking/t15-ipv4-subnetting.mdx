# IPv4 subnetting

## Question

How many usable host addresses are normally available in a conventional IPv4 /27 subnet, excluding its network and broadcast addresses?

## Options

| Option | Answer choice |
| --- | --- |
| A | 16 |
| B | 32 |
| C | 30 |
| D | 62 |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. 30

## Explanation

A /27 leaves 32-27=5 host bits: 2^5=32 addresses. Excluding the conventional network and broadcast addresses leaves 30.
