# IPv6 DNS record

## Question

Which DNS record type maps a host name directly to an IPv6 address?

## Options

| Option | Answer choice |
| --- | --- |
| A | AAAA |
| B | A |
| C | MX |
| D | TXT |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. AAAA

## Explanation

AAAA stores IPv6 addresses. A stores IPv4 addresses.
