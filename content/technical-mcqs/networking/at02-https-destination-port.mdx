# HTTPS destination port

## Question

An inventory site is available at https://inventory.example with no explicit port. Which destination port is normally used?

## Options

| Option | Answer choice |
| --- | --- |
| A | 21 |
| B | 53 |
| C | 80 |
| D | 443 |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. 443

## Explanation

HTTPS defaults to port 443. Port 80 is the default for plain HTTP.
