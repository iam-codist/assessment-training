# IPv4 subnet mask

## Question

What does a subnet mask identify for an IPv4 address?

## Options

| Option | Answer choice |
| --- | --- |
| A | Application and port |
| B | Certificate issuer |
| C | MAC vendor |
| D | Network and host portions |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Network and host portions

## Explanation

The mask marks which address bits identify the network prefix.
