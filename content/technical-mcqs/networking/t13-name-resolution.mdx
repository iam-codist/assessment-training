# Name resolution

## Question

A computer can reach a service by its IP address, but its configured hostname does not resolve. Which service should be investigated first?

## Options

| Option | Answer choice |
| --- | --- |
| A | DHCP lease renewal |
| B | File compression |
| C | NTP time synchronization |
| D | DNS |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. DNS

## Explanation

DNS maps names to address information. Failure of name resolution points to DNS before unrelated services.

</details>
