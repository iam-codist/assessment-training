# Conventional IPv4 subnet capacity

## Question

A lab is assigned a conventional IPv4 /26 subnet. How many host addresses can it assign after reserving the network and broadcast addresses?

## Options

| Option | Answer choice |
| --- | --- |
| A | 62 |
| B | 64 |
| C | 30 |
| D | 126 |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. 62

## Explanation

IPv4 has 32 bits, so /26 leaves six host bits. Subtract the network and broadcast addresses from 64 to get 62.
