# Switch forwarding

## Question

What does a basic Ethernet switch use to choose an outgoing port?

## Options

| Option | Answer choice |
| --- | --- |
| A | HTTP method |
| B | DNS suffix |
| C | Destination MAC address |
| D | Source TCP port |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Destination MAC address

## Explanation

The switch looks up the destination MAC in its forwarding table.
