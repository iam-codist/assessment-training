# DNS works independently of connectivity

## Question

A laptop can reach a server by IP but cannot resolve any hostname. Which setting should you check first?

## Options

| Option | Answer choice |
| --- | --- |
| A | Default printer |
| B | DNS resolver |
| C | Ethernet duplex |
| D | Screen resolution |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. DNS resolver

## Explanation

DNS translates hostnames to addresses. Working IP connectivity makes the configured resolver a sensible first check.
