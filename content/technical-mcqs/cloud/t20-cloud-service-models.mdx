# Cloud service models

## Question

A team rents virtual machines and installs and patches the guest operating system itself. Which cloud service model best describes this arrangement?

## Options

| Option | Answer choice |
| --- | --- |
| A | IaaS |
| B | SaaS |
| C | A fully managed email application |
| D | A public code repository |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. IaaS

## Explanation

IaaS provides infrastructure such as virtual machines while the customer manages the guest operating system and applications.
