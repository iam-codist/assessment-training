# Virtual machines and IaaS

## Question

You rent virtual machines and install and patch the guest operating system yourself. Which cloud model fits?

## Options

| Option | Answer choice |
| --- | --- |
| A | SaaS |
| B | PaaS |
| C | DNS |
| D | IaaS |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. IaaS

## Explanation

Infrastructure as a Service provides virtualized infrastructure while you manage the guest OS.
