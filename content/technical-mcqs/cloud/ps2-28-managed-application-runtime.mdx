# Managed application runtime

## Question

A team uploads application code while the provider manages the runtime and OS. Which model fits?

## Options

| Option | Answer choice |
| --- | --- |
| A | IaaS |
| B | On-premises hosting |
| C | PaaS |
| D | Colocation |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. PaaS

## Explanation

PaaS manages the application platform so the customer can deploy code.
