# Object storage

## Question

Which storage type best fits serving uploaded photos as independently addressed files through an API?

## Options

| Option | Answer choice |
| --- | --- |
| A | CPU cache |
| B | RAM |
| C | Object storage |
| D | Swap space |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. Object storage

## Explanation

Object storage stores each file as an object retrievable by a key.
