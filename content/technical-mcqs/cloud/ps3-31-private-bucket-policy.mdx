# Private bucket policy

## Question

Which measure limits access to a private cloud storage bucket?

## Options

| Option | Answer choice |
| --- | --- |
| A | Give objects longer names |
| B | Attach a narrowly scoped access policy |
| C | Increase storage capacity |
| D | Enable compression |

<details>
<summary>Show answer and explanation</summary>

## Answer

B. Attach a narrowly scoped access policy

## Explanation

An access policy limits which identities can perform which operations.
