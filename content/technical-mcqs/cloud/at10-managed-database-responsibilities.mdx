# Managed database responsibilities

## Question

A provider patches a managed database engine. Who still needs to decide which application accounts can read customer records?

## Options

| Option | Answer choice |
| --- | --- |
| A | The customer operating the application |
| B | The storage disk manufacturer |
| C | The network router |
| D | Nobody once patching is managed |

<details>
<summary>Show answer and explanation</summary>

## Answer

A. The customer operating the application

## Explanation

Managed patching covers part of the stack. The customer still sets application and database access permissions.
