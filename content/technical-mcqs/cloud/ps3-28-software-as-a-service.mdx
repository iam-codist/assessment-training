# Software as a service

## Question

A company subscribes to a browser-based email application operated by its vendor. Which model is it?

## Options

| Option | Answer choice |
| --- | --- |
| A | IaaS |
| B | PaaS |
| C | SaaS |
| D | Bare metal |

<details>
<summary>Show answer and explanation</summary>

## Answer

C. SaaS

## Explanation

SaaS delivers a ready-to-use managed application.
