# Storage for a database volume

## Question

A database engine expects a disk-like volume attached to its VM. Which storage model best matches this requirement?

## Options

| Option | Answer choice |
| --- | --- |
| A | Object storage |
| B | DNS caching |
| C | Message queue |
| D | Block storage |

<details>
<summary>Show answer and explanation</summary>

## Answer

D. Block storage

## Explanation

Block storage exposes a volume that a VM can use like a disk. Object storage exposes objects via an API.
