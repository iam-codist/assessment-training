# Replicating storage

## Question

Which arrangement keeps a separate copy available when a storage node fails?

## Options

| Option | Answer choice |
| --- | --- |
| A | Renaming |
| B | Compression |
| C | Replication |
| D | Tagging |

<details>
<summary>Show answer and explanation</summary>

## Answer

## Explanation
