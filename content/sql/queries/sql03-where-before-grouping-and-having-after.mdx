# WHERE before grouping and HAVING after

## Question

Use the [shared practice data](../../../SQL-PRACTICE.md). Find customers whose paid orders total at least 100. Show name and paid total, ordered by customer ID. Include the stated ordering so results are repeatable.

<details>
<summary>Show answer and explanation</summary>

## Answer

```sql
SELECT c.name, SUM(o.amount) AS paid_total
FROM customers AS c
JOIN orders AS o ON o.customer_id = c.id
WHERE o.status = 'paid'
GROUP BY c.id, c.name
HAVING SUM(o.amount) >= 100
ORDER BY c.id;
```

Expected rows:

| name | paid_total |
| --- | --- |
| Mira | 120 |
| Noah | 200 |

## Explanation

WHERE removes non-paid rows before aggregation. HAVING checks each resulting group’s total. Moving the paid filter into HAVING would not be an equivalent way to filter individual orders. Pia has a paid order but its total is only 90.
